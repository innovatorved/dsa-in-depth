Rollback Disjoint-Set Union & Offline Dynamic Connectivity Engine

A Rollback Disjoint-Set Union (Union-Find with undo stack) paired with a segment tree over the query timeline to solve offline dynamic graph connectivity with edge insertions and deletions.

Why Standard DSU Cannot Delete Edges—And How Rollback DSU Solves It

Standard Disjoint-Set Union with path compression destroys historical tree structure: an arbitrary number of descendants may have repointed directly to the root. However, if we keep union by size/rank without path compression:

  • Tree height is strictly bounded by ⌊log⁡2n⌋\lfloor \log_2 n \rfloor⌊log2​n⌋, so find(x) takes O(log⁡n)O(\log n)O(logn) worst-case time.
  • Every union(u, v) modifies exactly one parent pointer and one size entry, which can be undone in O(1)O(1)O(1) time by popping an undo stack!

Offline Dynamic Connectivity via Segment Tree Over Time

While arbitrary deletions cannot be undone out of LIFO order directly, any sequence of QQQ edge insertions, arbitrary edge deletions, and connectivity queries can be transformed into strictly LIFO operations over a Segment Tree of Time [0..Q−1][0..Q-1][0..Q−1]:

  1. Every edge eee added at time t1t_1t1​ and deleted at time t2t_2t2​ is alive over the contiguous time interval [t1,t2−1][t_1, t_2 - 1][t1​,t2​−1].
  2. Insert [t1,t2−1][t_1, t_2 - 1][t1​,t2​−1] into the segment tree over [0..Q−1][0..Q-1][0..Q−1], splitting into O(log⁡Q)O(\log Q)O(logQ) canonical intervals.
  3. Run a DFS over the segment tree:
    • Take snap = dsu.snapshot() and union all edges attached to the current segment-tree node.
    • Recurse to left and right children (or answer the query at leaf ttt).
    • Call dsu.rollback(snap) on exit—strictly LIFO!

Total time complexity: O((n+Qlog⁡Q)log⁡n)O((n + Q \log Q) \log n)O((n+QlogQ)logn).

  • Target Module: index.js (Step1)
  • Engineering Specification: Implement find(x) and union(u, v) on RollbackDSU. Omit path compression so find runs in O(log⁡n)O(\log n)O(logn) worst-case time while every union mutates only a single pointer and size.

Step 2: O(1) Per-Operation Undo Stack & Rollback

  • Core Mechanical Concept: O(1) Per-Operation Undo Stack & Rollback
  • Target Module: index.js (Step2)
  • Engineering Specification: Implement snapshot() and rollback(targetSnapshot) by popping { child, parent, prevSize } entries and restoring parent[child] = child and sz[parent] = prevSize.
  • Verification Invariant: verifies Step 2: O(1) Per-Operation Undo Stack & Rollback

Step 3: Edge Lifetime Decomposition Over a Time Segment Tree

  • Core Mechanical Concept: Edge Lifetime Decomposition Over a Time Segment Tree
  • Target Module: index.js (Step3)
  • Engineering Specification: Pair each addEdge(u, v) with its matching removeEdge(u, v) (or T−1T-1T−1 if never removed) to form a lifespan interval [tstart,tend][t_{\text{start}}, t_{\text{end}}][tstart​,tend​] and insert it into O(log⁡T)O(\log T)O(logT) nodes of a Segment Tree over [0..T−1][0..T-1][0..T−1].
  • Verification Invariant: verifies Step 3: Edge Lifetime Decomposition Over a Time Segment Tree

Step 4: Divide-and-Conquer Timeline DFS

  • Core Mechanical Concept: Divide-and-Conquer Timeline DFS
  • Target Module: index.js (Step4)
  • Engineering Specification: Traverse the time segment tree with DFS: on entering a node, snapshot the DSU and union all edges stored at that node; at leaves, answer queries; on exiting, rollback to the snapshot.
