Unifying Tries and KMP Prefix Automata

Scanning a text of length $|T|$ against $k$ patterns of total length $M = \sum |P_i|$ naively takes $O(k \cdot |T|)$. The Aho-Corasick automaton (1975) achieves $O(M + |T| + z)$ worst-case time—independent of the number of patterns $k$—by augmenting a keyword Trie with two sets of directed links:

  1. Failure Links (fail[u]): Point to the longest proper suffix of the string represented by node $u$ that also exists as a prefix in the Trie. Computed in $O(M)$ time via level-order BFS.
  2. Dictionary Output Links (outputLink[u]): Point directly to the longest proper suffix of $u$ that is a complete dictionary pattern. Without outputLink, traversing fail links at every character could visit $O(M)$ non-matching internal nodes; with outputLink, every step visits only actual matches in $O(1)$ per reported occurrence $z$.

Amortized Analysis of Text Scanning

Just as in KMP, each character of $T$ increases the current node depth by at most $1$, while every failure-link transition strictly decreases the node depth. Thus the total number of failure transitions across the entire text scan is bounded by $|T|$.
