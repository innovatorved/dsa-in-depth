Two's-Complement Indexing & O(n) Construction

A Fenwick Tree (Binary Indexed Tree) stores partial range aggregates keyed by the lowest set bit $\text{lsb}(i) = i \mathbin{\&} (-i)$ in two's-complement arithmetic:

  • Query (_sum): strips the lowest set bit via i -= i & -i to sum $O(\log n)$ disjoint power-of-two intervals covering $[1..k]$.
  • Update (_add): adds the lowest set bit via i += i & -i to update all ancestor intervals covering index $i$.
  • $O(n)$ Build: instead of calling _add $n$ times ($O(n \log n)$), each index $i$ propagates its accumulated value only to its immediate parent $j = i + (i \mathbin{\&} -i)$ in a single $O(n)$ forward sweep.

Range-Update Range-Query (RURQ) via Dual BITs

Let $D[i] = A[i] - A[i-1]$ be the difference array. After adding $\Delta$ to $[L, R]$, the prefix sum $\sum_{i=1}^k A[i]$ expands algebraically to:

$$\sum_{i=1}^{k} A[i] = \sum_{i=1}^{k} D[i] \cdot (k - i + 1) = k \sum_{i=1}^{k} D[i] - \sum_{i=1}^{k} Di$$

By maintaining $\text{BIT}_1[i] = D[i]$ and $\text{BIT}_2[i] = Di$, both rangeAdd(l, r, delta) and rangeSum(l, r) execute in $O(\log n)$ time using only two flat Float64Array buffers.
