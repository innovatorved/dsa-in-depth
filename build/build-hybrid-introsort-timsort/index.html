Overview

Musser’s hybrid IntroSort (median-of-three 3-way QuickSort + depth-bounded HeapSort fallback + small-subarray InsertionSort) paired with linear-time 3-way Quickselect.

Guided Implementation Walkthrough (4 Progressive Steps)

Step 1: Cache-Friendly Subarray Insertion Sort

  • Core Mechanical Concept: Low-Overhead O(N^2) Base Case for Small Partitions (N <= 16)
  • Target Module: index.js (insertionSortRange)
  • Engineering Specification: Implement insertionSortRange(arr, lo, hi, cmp) to sort arr[lo..hi] in place. For subarrays of length ≤16\le 16≤16, InsertionSort beats recursive QuickSort due to zero recursion overhead and sequential L1 cache hits.
  • Verification Invariant: sorts bounded subarray ranges in place via insertion sort

Step 2: In-Place Subarray HeapSort Fallback

  • Core Mechanical Concept: Guaranteeing O(N log N) Worst-Case When Recursion Depth Exhausts
  • Target Module: index.js (heapSortRange)
  • Engineering Specification: Implement heapSortRange(arr, lo, hi, cmp) over offset lo and length n = hi - lo + 1. Build a max-heap in O(n)O(n)O(n) using Floyd’s bottom-up siftDown from (n >> 1) - 1 down to 0, then repeatedly swap arr[lo] with arr[lo + end] and siftDown(0, end).
  • Verification Invariant: sorts subarrays in O(N log N) worst-case via in-place HeapSort

Step 3: Median-of-Three & Dijkstra 3-Way Partition

  • Core Mechanical Concept: Collapsing Duplicate Keys in O(N) via [ < pivot | == pivot | > pivot ]
  • Target Module: index.js (partition3Way)
  • Engineering Specification: Implement partition3Way(arr, lo, hi, cmp) returning [lt, gt]. Maintain [lo..lt-1] < pivot, [lt..i-1] == pivot, [i..gt] unclassified, and [gt+1..hi] > pivot. When i > gt, return [lt, gt].
  • Verification Invariant: partitions duplicate-heavy inputs into 3 regions and runs full IntroSort

Step 4: Linear-Time 3-Way Quickselect

  • Core Mechanical Concept: Pruning One Partition per Step to Find the k-th Order Statistic in O(N)
  • Target Module: index.js (quickselect)
  • Engineering Specification: Implement quickselect(arr, k, cmp) using partition3Way. If k >= lt && k <= gt, work[k] is in the equal-pivot band—return it immediately! Otherwise recurse/loop into [lo, lt - 1] if k < lt, or [gt + 1, hi] if k > gt.
  • Verification Invariant: selects exact k-th order statistics in expected O(N) time
