Spatial Partitioning via Alternating Hyperplanes

A kkk-d Tree (kkk-dimensional tree) is a binary space-partitioning tree where each internal node at depth ddd splits space with an axis-aligned hyperplane perpendicular to coordinate axis a=d mod ka = d \bmod ka=dmodk. Choosing the median point along axis aaa guarantees a balanced tree of height ⌈log⁡2(n+1)⌉\lceil \log_2(n + 1) \rceil⌈log2​(n+1)⌉ built in O(nlog⁡n)O(n \log n)O(nlogn) time.

Branch-and-Bound Hypersphere Pruning

Given a query point qqq, how do we find its exact nearest neighbor without scanning all nnn points?

  1. Maintain a running candidate ball of radius R=bestDistR = \text{bestDist}R=bestDist centered at qqq.
  2. At any splitting node ppp on axis aaa, compute the perpendicular distance from qqq to the splitting hyperplane: Δa=∣q[a]−p[a]∣\Delta_a = |q[a] - p[a]|Δa​=∣q[a]−p[a]∣
  3. Always search the near half-space first (the side of the hyperplane containing qqq). This rapidly shrinks RRR.
  4. Prune the far half-space whenever Δa≥R\Delta_a \ge RΔa​≥R (equivalently Δa2≥R2\Delta_a^2 \ge R^2Δa2​≥R2, avoiding square roots). Geometrically, if the query hypersphere of radius RRR does not intersect the splitting hyperplane, no point on the far side can possibly be closer than our current best!

Step 1: Alternating-Axis Median Partitioning

  • Target Module: index.js (Step1)
  • Engineering Specification: At depth ddd, select splitting axis axis=d mod k\text{axis} = d \bmod kaxis=dmodk, sort points along that coordinate, pick the median as the splitting hyperplane, and recursively build left and right subtrees.

Step 2: Orthogonal Bounding-Box Range Search

  • Core Mechanical Concept: Orthogonal Bounding-Box Range Search
  • Target Module: index.js (Step2)
  • Engineering Specification: Implement rangeSearch(minBounds, maxBounds) by pruning the left half-space when minBounds[axis] > node.point[axis] and pruning the right half-space when maxBounds[axis] < node.point[axis].
  • Verification Invariant: verifies Step 2: Orthogonal Bounding-Box Range Search

Step 3: Branch-and-Bound Nearest Neighbor Pruning

  • Core Mechanical Concept: Branch-and-Bound Nearest Neighbor Pruning
  • Target Module: index.js (Step3)
  • Engineering Specification: Always recurse into the near child containing target first to shrink bestSq quickly. Only recurse into the far child if the perpendicular distance to the splitting hyperplane satisfies (target[axis]−node.point[axis])2<bestSq(target[axis] - node.point[axis])^2 < bestSq(target[axis]−node.point[axis])2<bestSq.
  • Verification Invariant: verifies Step 3: Branch-and-Bound Nearest Neighbor Pruning

Step 4: Bounded k-Nearest Neighbors (k-NN)

  • Core Mechanical Concept: Bounded k-Nearest Neighbors (k-NN)
  • Target Module: index.js (Step4)
  • Engineering Specification: Generalize pruning to kkk nearest neighbors by comparing the hyperplane distance against the kkk-th best squared distance collected so far.
