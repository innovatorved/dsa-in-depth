Cartesian Trees Over Implicit Array Indices

A Treap combines a Binary Search Tree (ordered by key) with a Binary Heap (ordered by random priority). When we replace explicit keys with implicit indices—computed on the fly from size(node.left)—the treap becomes a dynamic array (or Rope) where every sequence operation runs in $O(\log n)$ expected time.

The Split-Merge Paradigm

All sequence mutations reduce to two primitives:

  1. split(t, k): Partitions treap t into [left, right] where left holds the first $k$ elements and right holds the remaining $n - k$ elements.
  2. merge(left, right): Concatenates two treaps under the precondition that all elements in left precede all elements in right, choosing the root with the larger random priority.

Lazy Range Reversal & Cut-and-Paste

To reverse a subarray $[l, r]$ in $O(\log n)$ time:

  1. Split into $T_1 = [0, l-1]$, $T_2 = [l, r]$, and $T_3 = [r+1, n-1]$.
  2. Toggle the lazy reversal bit T2.rev = !T2.rev.
  3. Merge merge(merge(T1, T2), T3).

Similarly, moving a block of text from $[l, r]$ to any new position requires two splits and two merges—the core operation of high-performance text editors and sequence engines.
