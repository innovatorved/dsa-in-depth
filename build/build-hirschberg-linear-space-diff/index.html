Breaking the O(nm)O(nm)O(nm) Memory Barrier for Backtracking

Computing the numeric Levenshtein edit distance between strings of length nnn and mmm requires only 2min⁡(n,m)2 \min(n, m)2min(n,m) cells of memory by keeping two rolling rows. However, recovering the actual alignment / diff transcript seems to require storing the full n×mn \times mn×m table of parent pointers (40 GB40\text{ GB}40 GB for two 100,000100{,}000100,000-char files!).

Dan Hirschberg (1975) solved this in O(n+m)O(n + m)O(n+m) space and O(nm)O(nm)O(nm) time:

  1. Every optimal path from (0,0)(0, 0)(0,0) to (n,m)(n, m)(n,m) in the DP grid must cross the middle row i=⌊n/2⌋i = \lfloor n/2 \rfloori=⌊n/2⌋ at some column k∗∈[0,m]k^* \in [0, m]k∗∈[0,m].
  2. The cost of the shortest path from (0,0)(0,0)(0,0) to (n,m)(n,m)(n,m) passing through (⌊n/2⌋,k)(\lfloor n/2 \rfloor, k)(⌊n/2⌋,k) is: Cost(k)=ForwardDP(A[0..⌊n/2⌋),  B[0..k))+ReverseDP(A[⌊n/2⌋..n),  B[k..m))\text{Cost}(k) = \text{ForwardDP}(A[0..\lfloor n/2 \rfloor),\; B[0..k)) + \text{ReverseDP}(A[\lfloor n/2 \rfloor..n),\; B[k..m))Cost(k)=ForwardDP(A[0..⌊n/2⌋),B[0..k))+ReverseDP(A[⌊n/2⌋..n),B[k..m))
  3. Both terms are computed for all k∈[0..m]k \in [0..m]k∈[0..m] simultaneously using two 2-row DP sweeps in O(m)O(m)O(m) space!
  4. Once k∗k^*k∗ is found, the problem splits into two subproblems of height n/2n/2n/2 and widths k∗k^*k∗ and m−k∗m - k^*m−k∗.
