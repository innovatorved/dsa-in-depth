# Product Truth — DSA In Depth (dsa-in-depth.vedgupta.in)

## Product Family & Platform
- **Platform**: `web` (static-first multi-page + SPA progressive enhancement, browser-native WebAssembly C++20/TypeScript coding labs, responsive desktop and mobile).
- **Product Family**: **In-Depth Engineering Series** (github.com/innovatorved):
  1. `dsa-in-depth` — Data Structures, Hardware Cache Hierarchy, Algorithmic Complexity & Pattern Visualizers (**Brand Accent**: Algorithmic Violet `#6D28D9` light / `#A78BFA` dark).
  2. `sql-in-depth` — Relational Algebra, Query Execution, B+Tree Storage, MVCC Concurrency & Production Database Internals (**Brand Accent**: Relational Ember `#C2410C` light / `#FB923C` dark).
  3. `system-design-in-depth` — Distributed Systems, Consensus, Caching, Replication & Large-Scale Architecture (**Brand Accent**: Distributed Teal `#0D9488` light / `#2DD4BF` dark).

## Audience & Core Job-to-be-Done
- **Who It Is For**: Software engineers and CS learners mastering how data structures and algorithms behave on real CPU cache hierarchies, memory layouts, and production systems.
- **Core Promise**: Every algorithm is grounded in invariants and hardware reality — learners step through live visualizers (cache lines, SIMD SwissTables, Red-Black rotations, Dinic level graphs), trace recurrences and amortized potentials, and verify implementations in a zero-backend C++20/TypeScript browser workbench.

## Aesthetic & Craft Principles
- **Tone**: Editorial technical clarity — calm, direct, diagrammatic, and open-source friendly.
- **Surfaces**: Warm Neutral Paper (`#F7F7F5` canvas, `#FFFFFF` elevated cards, `1px` crisp hairlines `#E6E4DF`) as default light mode; Neutral Charcoal (`#0F0F10` canvas, `#18181A` elevated surfaces — never harsh `#000000` glare or saturated navy) in dark mode.
- **Typography**: Self-hosted Geist (`15px` prose, `68ch` reading measure, `1.68` line-height, `28px` lesson `h1`, `20px` section `h2`) paired with Geist Mono (`tabular-nums` on every complexity table, step counter, and memory offset).
- **Zero-Noise Discipline**: No pop-up modals blocking content, no decorative left-border callout stripes, no gradient text, no stacked eyebrow kickers above headings, and sub-second page readiness.
