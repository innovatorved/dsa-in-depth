Suffix Arrays: Manber-Myers O(N log N) Prefix Doubling & SA-IS O(N) Overview

7 min read Module 4.2: Suffix Structures, Sequence Alignment & Data Compression Updated Oct 22, 2026
📄 Cheat Sheet

Explains Manber-Myers 2^k prefix doubling, equivalence classes, cyclic shift sorting, and how counting sort on the second component reduces O(N log^2 N) to O(N log N).

Intuition first

Udi Manber and Gene Myers (1990) asked: what if we discard all the nodes, child maps, and suffix links of a Suffix Tree and keep only the lexicographically sorted array of suffix starting indices SA[0..N−1]\text{SA}[0..N-1]SA[0..N−1]? This Suffix Array occupies just 4N4N4N bytes (int32_t SA[N]) and corresponds to the left-to-right leaf order of the Suffix Tree. Because every occurrence of a pattern P[0..M−1]P[0..M-1]P[0..M−1] is a prefix of a suffix, all occurrences of PPP form a single contiguous range in SA\text{SA}SA that can be found via binary search!

To sort all NNN suffixes without spending O(N2log⁡N)O(N^2 \log N)O(N2logN) time comparing O(N)O(N)O(N)-length strings, Manber-Myers Prefix Doubling sorts suffixes by their prefixes of length 2k2^k2k in step kkk: since a prefix of length 2k+12^{k+1}2k+1 is the concatenation of two already-ranked prefixes of length 2k2^k2k at indices iii and i+2ki + 2^ki+2k, each doubling step sorts pairs of integers (rankk[i],  rankk[i+2k])(\text{rank}_k[i],\; \text{rank}_k[i + 2^k])(rankk​[i],rankk​[i+2k]) via stable counting sort in O(N)O(N)O(N) time, completing in O(Nlog⁡N)O(N \log N)O(NlogN) time—or O(N)O(N)O(N) time via Nong, Zhang & Chan's SA-IS (Induced Sorting, 2009).

2. SA-IS (O(N)O(N)O(N) Suffix Array via Induced Sorting)

How does SA-IS (Nong, Zhang, Chan 2009) eliminate the log⁡N\log NlogN factor? It classifies every suffix iii into one of two types in a single right-to-left scan:

  • S-type (Smaller): Suffix S[i..]S[i..]S[i..] is lexicographically strictly smaller than the next suffix S[i+1..]S[i+1..]S[i+1..], i.e., S[i]<S[i+1]S[i] < S[i+1]S[i]<S[i+1] or (S[i]==S[i+1]S[i] == S[i+1]S[i]==S[i+1] and i+1i+1i+1 is S-type). The sentinel S[N-1] = \texttt{'\'}$ is S-type by definition.
  • L-type (Larger): Suffix S[i..]S[i..]S[i..] is strictly larger than S[i+1..]S[i+1..]S[i+1..].
  • LMS (Leftmost S-type) Positions: An index i>0i > 0i>0 is an LMS position if iii is S-type and i−1i - 1i−1 is L-type. Notice that two adjacent indices can never both be LMS, so there are at most N/2N / 2N/2 LMS positions!

SA-IS sorts only the LMS substrings (recursively if LMS substrings have ties, on a string of length ≤N/2\le N / 2≤N/2), places the sorted LMS suffixes at the ends of their character buckets, and then induces the sorted order of all L-type suffixes in one left-to-right pass (scanning SA\text{SA}SA left-to-right: if SA[j]−1\text{SA}[j] - 1SA[j]−1 is L-type, place it at the front of bucket S[SA[j]−1]S[\text{SA}[j] - 1]S[SA[j]−1]) followed by all S-type suffixes in one right-to-left pass! Bucket Partitioning & Induced Sorting Invariant

Within any first-character bucket c∈Σc \in \Sigmac∈Σ, every L-type suffix starting with ccc is strictly smaller than every S-type suffix starting with ccc! Why? An L-type suffix starting with ccc is followed by c…cdc \dots c dc…cd with d<cd < cd<c, whereas an S-type suffix starting with ccc is followed by c…cec \dots c ec…ce with e>ce > ce>c. Thus every character bucket [Bstart(c),Bend(c))[B_{\text{start}}(c), B_{\text{end}}(c))[Bstart​(c),Bend​(c)) partitions cleanly into an L-sub-bucket at the head and an S-sub-bucket at the tail.

Cache Locality of Shift-By-2^k Counting Sort

In Manber-Myers doubling, computing pn[i] = sa[i] - (1 << k) and incrementing cnt[c[pn[i]]]++ performs sequential reads over sa. To maximize L1 cache hits during the bucket-distribution loop, keep the equivalence class array c[0..N-1] as a flat std::vector<int32_t> and terminate the outer loop the instant the number of equivalence classes classes == N.

    const int n = static_cast<int>(str.size()) + 1;
    const int alpha = 256;
    std::vector<int> p(n), c(n), cnt(std::max(alpha, n), 0);

    for (int i = 0; i < n - 1; ++i) cnt[static_cast<uint8_t>(str[i])]++;
    cnt[0]++; // Sentinel at n - 1
    for (int i = 1; i < alpha; ++i) cnt[i] += cnt[i - 1];
    for (int i = 0; i < n; ++i) {
        uint8_t ch = (i == n - 1) ? 0 : static_cast<uint8_t>(str[i]);
        p[--cnt[ch]] = i;
    }

    c[p[0]] = 0;
    int classes = 1;
    for (int i = 1; i < n; ++i) {
        uint8_t ch_cur = (p[i] == n - 1) ? 0 : static_cast<uint8_t>(str[p[i]]);
        uint8_t ch_prv = (p[i - 1] == n - 1) ? 0 : static_cast<uint8_t>(str[p[i - 1]]);
        if (ch_cur != ch_prv) ++classes;
        c[p[i]] = classes - 1;
    }

    std::vector<int> pn(n), cn(n);
    for (int h = 0; (1 << h) < n && classes < n; ++h) {
        int step = 1 << h;
        for (int i = 0; i < n; ++i) {
            pn[i] = p[i] - step;
            if (pn[i] < 0) pn[i] += n;
        }
        std::fill(cnt.begin(), cnt.begin() + classes, 0);
        for (int i = 0; i < n; ++i) cnt[c[pn[i]]]++;
        for (int i = 1; i < classes; ++i) cnt[i] += cnt[i - 1];
        for (int i = n - 1; i >= 0; --i) p[--cnt[c[pn[i]]]] = pn[i];

        cn[p[0]] = 0;
        classes = 1;
        for (int i = 1; i < n; ++i) {
            std::pair<int, int> cur = {c[p[i]], c[(p[i] + step) % n]};
            std::pair<int, int> prv = {c[p[i - 1]], c[(p[i - 1] + step) % n]};
            if (cur != prv) ++classes;
            cn[p[i]] = classes - 1;
        }
        c.swap(cn);
    }

    p.erase(p.begin()); // Remove the '' sentinel suffix at p[0] == n - 1
    return p;
}

// Returns half-open range [L, R) in SA where pattern P occurs as a prefix
std::pair<int, int> suffix_array_search(std::string_view text,
                                        const std::vector<int>& sa,
                                        std::string_view pat) {
    auto cmp_lower = [&](int idx, std::string_view q) {
        return text.substr(idx, q.size()) < q;
    };
    auto cmp_upper = [&](std::string_view q, int idx) {
        return q < text.substr(idx, q.size());
    };
    auto l = std::lower_bound(sa.begin(), sa.end(), pat, cmp_lower);
    auto r = std::upper_bound(l, sa.end(), pat, cmp_upper);
    return {static_cast<int>(l - sa.begin()), static_cast<int>(r - sa.begin())};
}

Key Takeaways

A Suffix Array SA[0..N-1] stores the starting indices of all suffixes of S in lexicographical order, using 4N bytes instead of a Suffix Tree's 20N-48N bytes.
Manber-Myers prefix doubling sorts suffixes by 2^k-length prefixes in O(N log N) time by shifting SA by -2^k and running one stable counting sort on the primary rank c[pn[i]] per doubling step.
SA-IS achieves O(N) suffix array construction by partitioning suffixes into L-type and S-type, recursively sorting at most N/2 Leftmost-S (LMS) positions, and inducing the full order in two linear sweeps.
