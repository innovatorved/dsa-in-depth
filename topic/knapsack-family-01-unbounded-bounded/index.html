Intuition first

The entire Knapsack family revolves around one question: how many copies of item i can we take? Flipping the 1D capacity loop from backward (W down to w_i) to forward (w_i up to W) turns 0/1 Knapsack into Unbounded Knapsack; packing boolean states into std::bitset<W> speeds up Subset Sum by 64x via word-level shift-OR; and decomposing count k_i into powers of two solves Bounded Knapsack in O(N W log k).

1. The Four Canonical Knapsack Variants

Given NNN item types with weights wiw_iwi​, values viv_ivi​, and knapsack capacity WWW:

  1. 0/1 Knapsack (ci∈{0,1}c_i \in \{0, 1\}ci​∈{0,1}): Each item taken at most once. 1D recurrence iterates www backward from WWW down to wiw_iwi​: dp[w]=max⁡(dp[w],  dp[w−wi]+vi)dp[w] = \max(dp[w],\; dp[w - w_i] + v_i)dp[w]=max(dp[w],dp[w−wi​]+vi​)
  2. Unbounded / Complete Knapsack (ci∈{0,1,2,… }c_i \in \{0, 1, 2, \dots\}ci​∈{0,1,2,…}): Unlimited copies of each item. 1D recurrence iterates www forward from wiw_iwi​ up to WWW so dp[w−wi]dp[w - w_i]dp[w−wi​] already includes item iii: dp[w]=max⁡(dp[w],  dp[w−wi]+vi)dp[w] = \max(dp[w],\; dp[w - w_i] + v_i)dp[w]=max(dp[w],dp[w−wi​]+vi​)
  3. Subset Sum Bitset Acceleration (vi=0/1v_i = 0/1vi​=0/1 feasibility): Can a subset sum to www? Pack the boolean array into 64-bit machine words (std::bitset). Adding item wiw_iwi​ becomes a single word-parallel shift-OR: bits∣=(bits≪wi)  ⟹  O ⁣(N⋅W64)\text{bits} \mathrel{|=} (\text{bits} \ll w_i) \quad \implies \quad O\!\left(\frac{N \cdot W}{64}\right)bits∣=(bits≪wi​)⟹O(64N⋅W​)
  4. Bounded Knapsack (ci∈{0,1,…,ki}c_i \in \{0, 1, \dots, k_i\}ci​∈{0,1,…,ki​}): At most kik_iki​ copies of item iii. Naive transition checks all c∈[0..ki]c \in [0..k_i]c∈[0..ki​] in O(NW⋅ki)O(N W \cdot k_i)O(NW⋅ki​). How do we remove the kik_iki​ factor?

Core Invariant — Binary Splitting (O(NWlog⁡K)O(N W \log K)O(NWlogK)) & Monotonic Queue (O(NW)O(N W)O(NW)) for Bounded Knapsack

Method 1 (Binary Splitting): Any integer kik_iki​ can be decomposed into ⌊log⁡2ki⌋+1\lfloor \log_2 k_i \rfloor + 1⌊log2​ki​⌋+1 bundles with sizes 1,2,4,…,2p−11, 2, 4, \dots, 2^{p-1}1,2,4,…,2p−1 plus the remainder R=ki−(2p−1)R = k_i - (2^p - 1)R=ki​−(2p−1). Every integer in [0,ki][0, k_i][0,ki​] is uniquely expressible as a subset sum of these ≈log⁡2ki\approx \log_2 k_i≈log2​ki​ bundles! Running standard 0/1 Knapsack on these bundles reduces time to O(W∑log⁡ki)O(W \sum \log k_i)O(W∑logki​).

2. The S\sqrt{S}S​ Frequency Compression Trick for Subset Sum (∑wi=S\sum w_i = S∑wi​=S)

When the sum of all item weights is ∑i=1Nwi=S\sum_{i=1}^N w_i = S∑i=1N​wi​=S, at most O(S)O(\sqrt{S})O(S​) distinct weight values can exist! Why? Because the minimum sum of ddd distinct positive integers is 1+2+⋯+d=d(d+1)/2≤S  ⟹  d≤2S1 + 2 + \dots + d = d(d+1)/2 \le S \implies d \le \sqrt{2S}1+2+⋯+d=d(d+1)/2≤S⟹d≤2S​. By grouping identical weights into (weight, count) pairs and applying binary splitting (or packing pairs of equal weights into a next-level weight 2w2w2w until at most 2 copies of each weight remain), Subset Sum on ∑wi=S\sum w_i = S∑wi​=S runs in O ⁣(SS64)O\!\left(\frac{S \sqrt{S}}{64}\right)O(64SS​​) time!

Hardware Reality — AVX2 / AVX-512 Word-Level Bitset Parallelism

In C++, std::bitset<100001> dp; dp |= (dp << w); compiles under -O3 -march=native to a tight loop of 256-bit AVX2 (VPXOR/VPOR/VPSLLQ) or 512-bit AVX-512 instructions processing 256 to 512 capacity states per CPU clock cycle. For N=2000,W=100,000N = 2000, W = 100{,}000N=2000,W=100,000, scalar DP executes 2×1082 \times 10^82×108 loop iterations (~150 ms), whereas std::bitset executes 2000×(100000/256)≈7.8×1052000 \times (100000 / 256) \approx 7.8 \times 10^52000×(100000/256)≈7.8×105 SIMD instructions in under 1.2 milliseconds.

#include <algorithm>
#include <bitset>
#include <cstdint>
#include <deque>
#include <vector>

struct BoundedItem {
    int weight;
    long long value;
    int count;
};

// 1. Bounded Knapsack in O(W * sum(log k_i)) via Binary Splitting
long long bounded_knapsack_binary_split(const std::vector<BoundedItem>& items, int capacity) {
    std::vector<long long> dp(capacity + 1, 0);

    auto apply_01_item = [&](int w, long long v) {
        for (int cap = capacity; cap >= w; --cap) {
            dp[cap] = std::max(dp[cap], dp[cap - w] + v);
        }
    };

    for (const auto& item : items) {
        int rem = item.count;
        for (int b = 1; b <= rem; b <<= 1) {
            int bundle_w = b * item.weight;
            if (bundle_w <= capacity) {
                apply_01_item(bundle_w, b * item.value);
            }
            rem -= b;
        }
        if (rem > 0 && rem * item.weight <= capacity) {
            apply_01_item(rem * item.weight, rem * item.value);
        }
    }
    return dp[capacity];
}

// 2. Bounded Knapsack in Strict O(N * W) Time via Monotonic Deque over Residue Classes
long long bounded_knapsack_monotonic_queue(const std::vector<BoundedItem>& items, int capacity) {
    std::vector<long long> dp(capacity + 1, 0);
    std::deque<std::pair<int, long long>> dq; // (quotient q, shifted_val = dp[q*w + r] - q*v)

    for (const auto& item : items) {
        const int w = item.weight;
        const long long v = item.value;
        const int k = item.count;
        if (w > capacity || k == 0) continue;

        for (int r = 0; r < w; ++r) {
            dq.clear();
            int max_q = (capacity - r) / w;
            for (int q = 0; q <= max_q; ++q) {
                long long shifted = dp[q * w + r] - q * v;
                while (!dq.empty() && dq.back().second <= shifted) {
                    dq.pop_back();
                }
                dq.emplace_back(q, shifted);
                // Evict window elements older than q - k
                if (dq.front().first < q - k) {
                    dq.pop_front();
                }
                dp[q * w + r] = dq.front().second + q * v;
            }
        }
    }
    return dp[capacity];
}

// 3. O(N * W / 64) Word-Parallel Subset Sum using std::bitset
template <std::size_t MAXW = 100001>
bool subset_sum_bitset(const std::vector<int>& weights, int target) {
    if (target < 0 || static_cast<std::size_t>(target) >= MAXW) return false;
    std::bitset<MAXW> reachable;
    reachable.set(0);
    for (int w : weights) {
        reachable |= (reachable << w);
    }
    return reachable.test(target);
}

Key Takeaways

0/1 Knapsack iterates capacity backward (W down to w_i) so each item is used at most once; Unbounded Knapsack iterates forward (w_i up to W) to allow unlimited reuse.
Binary splitting decomposes count k_i into powers of two 1, 2, 4, ... plus remainder R, reducing Bounded Knapsack to O(W sum log k_i) 0/1 Knapsack steps.
Grouping capacities by residue r = w mod w_i transforms Bounded Knapsack into a sliding-window maximum solvable in O(N * W) via a monotonic deque.
When capacity W is huge (10^9) but total value V is small (10^5), swap state and value: compute the minimum weight needed to achieve value v in O(N * V).
