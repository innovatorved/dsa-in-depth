Intuition first

Why does inserting NNN distinct keys in a uniformly random permutation π∈SN\pi \in S_Nπ∈SN​ into an ordinary, unbalanced BST produce a balanced tree with expected search depth O(log⁡N)O(\log N)O(logN) and expected height ≈4.311ln⁡N\approx 4.311 \ln N≈4.311lnN, without performing a single tree rotation? Because a Randomly Built BST is the exact structural trace—the static execution tree—of Randomized QuickSort!

The first key π1\pi_1π1​ inserted into the BST becomes the root, partitioning all remaining N−1N - 1N−1 keys into L={x<π1}L = \{x < \pi_1\}L={x<π1​} (which route left) and R={x>π1}R = \{x > \pi_1\}R={x>π1​} (which route right). That is identical to QuickSort choosing π1\pi_1π1​ as the first pivot and comparing every other element against π1\pi_1π1​. Consequently, the total internal path length of a randomly built BST equals the exact number of key comparisons made by QuickSort.

A strictly balanced AVL tree has worst-case height ≤1.44log⁡2N\le 1.44 \log_2 N≤1.44log2​N and average depth ≈1.04log⁡2N\approx 1.04 \log_2 N≈1.04log2​N, whereas a Randomly Built BST has average depth ≈1.386log⁡2N\approx 1.386 \log_2 N≈1.386log2​N—only 34% more comparisons on average, while requiring zero balance-factor metadata bytes and zero pointer-modifying rotations! // C++20: Offline Randomized BST Builder via Fisher-Yates Shuffle + Exact Harmonic Depth Estimator
#include <vector>
#include <random>
#include <cmath>

struct Node {
    int key;
    Node *left = nullptr, *right = nullptr;
    explicit Node(int k) : key(k) {}
};

void insertBST(Node*& root, int key) {
    Node** curr = &root;
    while (*curr != nullptr) {
        curr = (key < (*curr)->key) ? &((*curr)->left) : &((*curr)->right);
    }
    *curr = new Node(key);
}

// Eliminates O(N) sorted-input degeneration before bulk BST insertion
Node* buildRandomBST(std::vector<int> keys, uint64_t seed = 42) {
    std::mt19937_64 rng(seed);
    for (size_t i = keys.size(); i > 1; --i) {
        std::uniform_int_distribution<size_t> dist(0, i - 1);
        std::swap(keys[i - 1], keys[dist(rng)]);
    }
    Node* root = nullptr;
    for (int k : keys) insertBST(root, k);
    return root;
}

// Exact theoretical expected depth of a random node in an N-node Randomly Built BST
double expectedRandomBSTDepth(int n) {
    double harmonic = 0.0;
    for (int k = 1; k <= n; ++k) harmonic += 1.0 / k;
    return (2.0 * (n + 1) / n) * harmonic - 4.0;
}

Concept Check Expected Depth and Height Constants of a Randomly Built BST recall

When N distinct keys are inserted in a uniformly random permutation into an initially empty unbalanced BST, what are the asymptotic expected node depth E[d(x)] and expected tree height E[h(T)]?

By the QuickSort-BST bijection, average node depth is 2 ln N ≈ 1.386 log₂ N (only 39% deeper than a complete binary tree), and by Reed's theorem (2003), expected maximum height is α ln N ≈ 4.311 ln N ≈ 2.988 log₂ N.
Concept Check Ancestor Indicator Probability in a Randomly Built BST apply

Let z₁ < z₂ < ... < z_N be the sorted keys inserted in a uniformly random permutation into a BST. What is the exact probability that z₃ is an ancestor of z₉?

Node z_i is an ancestor of z_j if and only if z_i is the very first element inserted among the contiguous sorted range {z_min(i,j), ..., z_max(i,j)}. For i=3 and j=9, the range {z₃, z₄, z₅, z₆, z₇, z₈, z₉} contains 9 - 3 + 1 = 7 elements, so z₃ is inserted first among them with probability 1/7.
Concept Check Isomorphism Between Randomly Built BSTs and QuickSort apply

Why does the total internal path length D(T) = ∑ d(z_i) of a Randomly Built BST equal the exact number of key comparisons executed by Randomized QuickSort using the same permutation of pivots?

Inserting z_j down the BST compares z_j against every ancestor z_i on its search path. In QuickSort, z_j is compared against pivot z_i if and only if z_i is the first pivot selected from Z_{ij}, meaning z_i is an ancestor of z_j in the BST.
Concept Check Random Permutation Distribution vs Uniform Catalan Topology Distribution staff

For N = 3 keys {1, 2, 3}, there are 3! = 6 input permutations but only C₃ = 5 distinct BST shapes. How does sampling a BST via a uniformly random input permutation differ from sampling uniformly among all C_N Catalan binary tree topologies?

A balanced tree has many independent subtrees whose insertions can be interleaved in exponentially many ways (producing the same BST), whereas a degenerate chain is produced by only 1 permutation. Thus random permutations concentrate measure on O(log N)-height trees, while uniform Catalan trees have expected height √(π N).

Key Takeaways

A Randomly Built BST is structurally isomorphic to the pivot partition tree of Randomized QuickSort.
Node z_i is an ancestor of z_j if and only if z_i is the very first element inserted from the contiguous sorted range {z_min(i,j), ..., z_max(i,j)}, occurring with probability 1 / (|j - i| + 1).
Summing the harmonic series over all pairs proves expected node depth is 2(1 + 1/N)H_N - 4 ≈ 1.386 log₂ N and expected height is ≈ 4.311 ln N ≈ 2.988 log₂ N.
Random permutations over-weight balanced trees compared to uniform Catalan tree sampling, which has expected height Θ(√N).
