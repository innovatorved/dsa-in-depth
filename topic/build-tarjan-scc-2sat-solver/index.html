Walks through encoding boolean constraints into an implication graph and extracting truth assignments from Tarjan SCC IDs.

Intuition first

In this Build Lab, we assemble a complete, production-grade Tarjan SCC Condensation Engine and Linear-Time 2-SAT Solver. Many seemingly intractable scheduling, circuit-routing, and configuration conflicts—where every constraint involves choosing between two options or avoiding pairwise conflicts—reduce directly to 2-SAT.

By indexing variable $x_i$ as vertex $2i$ and its negation $\neg x_i$ as $2i \oplus 1$, we can encode OR, XOR, NAND, and implication constraints into a compact CSR/adjacency graph, decompose it into Strongly Connected Components in a single $O(N + M)$ pass, and read off a verified boolean assignment directly from the topological order of the SCC IDs.

Engineering Blueprint: Literal Encoding & Constraint Gadgets

Given $N$ boolean variables $x_0, x_1, \dots, x_{N-1}$, we allocate $2N$ vertices in the implication graph. For each variable $i \in [0, N-1]$:

  • Vertex $2i$ represents the positive literal $x_i$ (isTrue = true).
  • Vertex $2i + 1$ represents the negated literal $\neg x_i$ (isTrue = false).
  • Negating any literal vertex $u \in [0, 2N-1]$ is a single branchless bitwise XOR: $\neg u = u \oplus 1$.
Formal Gadget Dictionary — Reducing Boolean Constraints to 2-SAT Clauses

Every binary boolean constraint over literals $a, b$ reduces to one or more base clauses $(p \lor q)$, each adding two directed edges $(\neg p \to q)$ and $(\neg q \to p)$:

  • At least one true ($a \lor b$): addClause(a, b) $\implies (\neg a \to b), (\neg b \to a)$.
  • Implication ($a \Rightarrow b$): Equivalent to $(\neg a \lor b) \implies$ addClause(a ^ 1, b).
  • Mutual Exclusion / At most one true ($\neg(a \land b)$): Equivalent to $(\neg a \lor \neg b) \implies$ addClause(a ^ 1, b ^ 1).
  • XOR / Exactly one true ($a \oplus b$): Combine $(a \lor b) \land (\neg a \lor \neg b)$.
  • Equality ($a \iff b$): Combine $(\neg a \lor b) \land (a \lor \neg b)$.
  • Force $a$ to be True (Unit Clause): Equivalent to $(a \lor a) \implies$ single edge $(\neg a \to a)$.

Hardware Reality — Prefix-Optimization for "At Most One" Over $K$ Variables

Suppose a constraint requires at most one of $K$ literals $\{l_0, l_1, \dots, l_{K-1}\}$ to be true. Naive pairwise mutex adds $\binom{K}{2} = O(K^2)$ edges! Instead, introduce $K$ auxiliary prefix variables $p_0, \dots, p_{K-1}$ where $p_j$ means "$\bigvee_{r=0}^j l_r$ is true", adding implications $l_j \Rightarrow p_j$, $p_{j-1} \Rightarrow p_j$, and $p_{j-1} \Rightarrow \neg l_j$. This reduces the edge count from $O(K^2)$ to strictly $3K = O(K)$ linear edges!

Complete Implementation: Linear-Time 2-SAT Solver & Condensation DAG Builder

#include <vector>
#include <algorithm>
#include <cstdint>

class TwoSatSolver {
public:
    explicit TwoSatSolver(int numVars)
        : n(numVars), adj(2 * numVars), tin(2 * numVars, 0),
          low(2 * numVars, 0), comp(2 * numVars, -1),
          onStack(2 * numVars, 0), assignment(numVars, false) {
        st.reserve(2 * numVars);
    }

    static int lit(int var, bool isTrue) noexcept {
        return 2 * var + (isTrue ? 0 : 1);
    }

    // Adds (u OR v) where u, v are literal indices in [0, 2n-1]
    void addClause(int u, int v) {
        adj[u ^ 1].push_back(v);
        adj[v ^ 1].push_back(u);
    }

    void addXor(int u, int v) {
        addClause(u, v);
        addClause(u ^ 1, v ^ 1);
    }

    void addEq(int u, int v) {
        addClause(u ^ 1, v);
        addClause(u, v ^ 1);
    }

    bool solve() {
        for (int i = 0; i < 2 * n; ++i) {
            if (tin[i] == 0) dfs(i);
        }
        for (int i = 0; i < n; ++i) {
            if (comp[2 * i] == comp[2 * i + 1]) return false;
            // In Tarjan's SCC, smaller component ID means closer to a sink in the DAG
            assignment[i] = (comp[2 * i] < comp[2 * i + 1]);
        }
        return true;
    }

    const std::vector<bool>& values() const noexcept { return assignment; }

private:
    int n, timer = 0, sccCount = 0;
    std::vector<std::vector<int>> adj;
    std::vector<int> tin, low, comp, st;
    std::vector<uint8_t> onStack;
    std::vector<bool> assignment;

    void dfs(int u) {
        tin[u] = low[u] = ++timer;
        st.push_back(u);
        onStack[u] = 1;
        for (int v : adj[u]) {
            if (tin[v] == 0) {
                dfs(v);
                low[u] = std::min(low[u], low[v]);
            } else if (onStack[v]) {
                low[u] = std::min(low[u], tin[v]);
            }
        }
        if (low[u] == tin[u]) {
            while (true) {
                int w = st.back();
                st.pop_back();
                onStack[w] = 0;
                comp[w] = sccCount;
                if (w == u) break;
            }
            ++sccCount;
        }
    }
};
Failure Mode — Inverting < vs > Between Tarjan and Kosaraju

In Tarjan's algorithm, SCCs are popped in post-order (sinks get ID $0$, sources get ID $K-1$), so the sink-most literal satisfies $\text{comp}[2i] < \text{comp}[2i+1]$. In Kosaraju's algorithm, the second pass discovers sources first (sources get ID $0$, sinks get ID $K-1$), so the inequality reverses to $\text{comp}[2i] > \text{comp}[2i+1]$. Mixing the two conventions sets every implied variable to False instead of True!

Key Takeaways

Representing positive literal x_i as 2i and negative literal ~x_i as 2i + 1 enables O(1) branchless negation via bitwise XOR (u ^ 1).
Every binary boolean operator (OR, IMPLIES, NAND, XOR, EQ) reduces to at most two 2-SAT clauses (four directed implication edges).
Prefix variable encoding reduces 'at most one of K literals' constraints from O(K^2) edges to O(K) edges.
In Tarjan's SCC numbering, sinks receive smaller component IDs than sources, so x_i = (comp[2i] < comp[2i+1]) yields a valid truth assignment whenever comp[2i] != comp[2i+1].
