Covers the Catalan-sized space of binary expression trees and why interval length must be the outer topological loop.

Intuition first

When a decision splits a contiguous range [i, j] into two independent sub-ranges [i, k] and [k+1, j]—like parenthesizing matrix multiplications, choosing the root of a Binary Search Tree, or slicing a convex polygon with a triangle—prefixes alone aren't enough. We must parameterize states by both endpoints (i, j) and iterate in increasing order of interval length L = j - i + 1.

1. Catalan Tree Spaces & The Interval Length Topological Order

How many ways can we parenthesize a product of nnn matrices A1A2⋯AnA_1 A_2 \cdots A_nA1​A2​⋯An​, construct a Binary Search Tree on nnn sorted keys, or triangulate a convex (n+1)(n+1)(n+1)-gon? The answer to all three is the (n−1)(n-1)(n−1)-th Catalan Number:

Cn−1=1n(2n−2n−1)=Θ ⁣(4nn3/2)C_{n-1} = \frac{1}{n}\binom{2n-2}{n-1} = \Theta\!\left(\frac{4^n}{n^{3/2}}\right)Cn−1​=n1​(n−12n−2​)=Θ(n3/24n​)

Because the last operation merges two contiguous sub-intervals [i,k][i, k][i,k] and [k+1,j][k+1, j][k+1,j] into [i,j][i, j][i,j], any subproblem is uniquely identified by its pair of endpoints (i,j)(i, j)(i,j) with 0≤i≤j<n0 \le i \le j < n0≤i≤j<n—collapsing Θ(4n/n3/2)\Theta(4^n / n^{3/2})Θ(4n/n3/2) trees into just (n+12)=Θ(n2)\binom{n+1}{2} = \Theta(n^2)(2n+1​)=Θ(n2) distinct subproblems!

Core Invariant — Interval Length Topological Ordering (len=j−i+1\text{len} = j - i + 1len=j−i+1)

In Interval DP, state dp[i][j]dp[i][j]dp[i][j] depends on shorter intervals dp[i][k]dp[i][k]dp[i][k] (to the left in row iii) and dp[k+1][j]dp[k+1][j]dp[k+1][j] (below in column jjj). Therefore, naive row-major iteration (for i = 0..n-1: for j = i..n-1) is invalid because dp[k+1][j]dp[k+1][j]dp[k+1][j] belongs to a later row k+1>ik+1 > ik+1>i that hasn't been computed yet!
Two valid topological orders exist:
1. By Increasing Length: for (int len = 2; len <= n; ++len) for (int i = 0; i + len - 1 < n; ++i).
2. By Decreasing Left Endpoint: for (int i = n - 1; i >= 0; --i) for (int j = i + 1; j < n; ++j).

Hardware Reality — Transposing the Right Operand for Cache-Friendly O(N3)O(N^3)O(N3) Loops

In the innermost loop for (int k = i; k < j; ++k) of dp[i][k] + dp[k+1][j], accessing dp[i][k] streams sequentially across row iii (stride 1, L1 cache hit), whereas accessing dp[k+1][j] jumps down column jjj with stride NNN—causing an L1/L2 cache miss on every step when N≥512N \ge 512N≥512! Maintaining a transposed mirror array dpT[j][k+1] = dp[k+1][j] turns both inner-loop reads into unit-stride sequential scans, allowing the compiler to auto-vectorize the kkk-loop with AVX2 (VPMINSD/VPADDD) for a 4×4\times4×–6×6\times6× wall-clock speedup.

#include <algorithm>
#include <cstdint>
#include <limits>
#include <vector>

// 1. Matrix Chain Multiplication with Transpose-Cache Optimization (p has size n + 1)
long long matrix_chain_multiplication(const std::vector<long long>& p) {
    const int n = static_cast<int>(p.size()) - 1;
    if (n <= 1) return 0;
    constexpr long long INF = 1LL << 60;

    // dp[i][j] = min scalar multiplications for A_i .. A_j
    // dpT[j][i] = transposed copy of dp[i][j] so inner k-loop has stride-1 on both arrays!
    std::vector<std::vector<long long>> dp(n, std::vector<long long>(n, 0));
    std::vector<std::vector<long long>> dpT(n, std::vector<long long>(n, 0));

    for (int len = 2; len <= n; ++len) {
        for (int i = 0; i + len - 1 < n; ++i) {
            const int j = i + len - 1;
            const long long outer_p = p[i] * p[j + 1];
            long long best = INF;
            for (int k = i; k < j; ++k) {
                // Both dp[i][k] and dpT[j][k + 1] are contiguous in memory along index k!
                long long cost = dp[i][k] + dpT[j][k + 1] + outer_p * p[k + 1];
                if (cost < best) best = cost;
            }
            dp[i][j] = best;
            dpT[j][i] = best;
        }
    }
    return dp[0][n - 1];
}

// 2. Burst Balloons: Guess the LAST balloon popped inside open interval (i, j)
long long max_coins_burst_balloons(const std::vector<int>& nums) {
    // Pad with virtual boundary balloons of value 1 at both ends
    std::vector<long long> a;
    a.reserve(nums.size() + 2);
    a.push_back(1);
    for (int x : nums) if (x > 0) a.push_back(x);
    a.push_back(1);

    const int m = static_cast<int>(a.size());
    std::vector<std::vector<long long>> dp(m, std::vector<long long>(m, 0));

    // len is the distance j - i between open interval boundaries (minimum 2)
    for (int len = 2; len < m; ++len) {
        for (int i = 0; i + len < m; ++i) {
            const int j = i + len;
            const long long boundary_prod = a[i] * a[j];
            long long best = 0;
            for (int k = i + 1; k < j; ++k) {
                best = std::max(best, dp[i][k] + dp[k][j] + boundary_prod * a[k]);
            }
            dp[i][j] = best;
        }
    }
    return dp[0][m - 1];
}

Key Takeaways

Interval DP collapses Catalan-many binary expression trees O(4^N / N^1.5) into O(N^2) contiguous sub-range states dp[i][j].
Always iterate in topological order of increasing interval length len = j - i + 1 (or decreasing left endpoint i) so shorter sub-intervals are finalized first.
When removing an element causes the left and right sub-ranges to touch, guess the LAST element operated on inside (i, j) to keep subproblems independent.
Maintaining a transposed copy dpT[j][k+1] = dp[k+1][j] converts column-strided memory reads into unit-stride cache-line scans.
