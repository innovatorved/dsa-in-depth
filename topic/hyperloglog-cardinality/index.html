Intuition first

How does Redis (PFADD / PFCOUNT), BigQuery (APPROX_COUNT_DISTINCT), or DuckDB count 10910^9109 distinct user IDs (COUNT(DISTINCT user_id)) using only 1.5 KB to 12 KB of memory with <0.81%< 0.81\%<0.81% standard error? If we hash every element uniformly to a 64-bit integer, a pattern of ρ−1\rho - 1ρ−1 leading zeros followed by a 1 (e.g., 00001..., where ρ=5\rho = 5ρ=5) occurs with probability 2−ρ2^{-\rho}2−ρ. Thus, if the maximum position of the leftmost 1-bit seen across a stream of distinct hashes is R=max⁡xρ(h(x))R = \max_x \rho(h(x))R=maxx​ρ(h(x)), then 2R2^R2R is a rough order-of-magnitude estimate of the cardinality nnn.

A single register RRR has huge variance (powers of 2) and is easily skewed by a single lucky hash (000000000001...). HyperLogLog (Flajolet, Fusy, Gandouet, Meunier, 2007) uses the top ppp bits of each 64-bit hash to partition the stream into m=2pm = 2^pm=2p substreams (e.g., p=14  ⟹  m=16,384p = 14 \implies m = 16{,}384p=14⟹m=16,384 registers of 6 bits each = 12 KB12\text{ KB}12 KB) and combines the mmm register maxima via the Harmonic Mean, achieving a tight standard error of σ≈1.04m\sigma \approx \frac{1.04}{\sqrt{m}}σ≈m​1.04​.

Hardware Reality: Hardware LZCNT / std::countl_zero & Sentinel Bit Trick

Every x86-64 (ABM/BMI1 LZCNT) and ARM64 (CLZ) processor computes the number of leading zeros in a 64-bit register in 1 to 3 clock cycles via std::countl_zero(w). To prevent ρ(w)\rho(w)ρ(w) from exceeding 64−p+164 - p + 164−p+1 when all 64−p64 - p64−p bits of www are zero, shift www left by ppp bits and bitwise-OR a sentinel 1 at bit p−1p - 1p−1: w_shifted = (h << p) | (1ULL << (p - 1)). Then std::countl_zero(w_shifted) + 1 is branchless, well-defined even when w=0w = 0w=0, and never invokes undefined behavior on legacy BSR instructions!

// C++20: HyperLogLog (64-bit hash, p in [4..18]) with Sentinel CLZ & LinearCounting
#include <vector>
#include <cstdint>
#include <bit>
#include <cmath>
#include <algorithm>

class HyperLogLog {
    uint32_t p_;
    uint32_t m_;
    double alphaMM_;
    std::vector<uint8_t> regs_;

    static uint64_t hash64(uint64_t x) noexcept {
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
        x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
        return x ^ (x >> 31);
    }

public:
    explicit HyperLogLog(uint32_t p = 14)
        : p_(std::clamp(p, 4U, 18U)), m_(1U << p_), regs_(m_, 0) {
        double alpha = 0.7213 / (1.0 + 1.079 / static_cast<double>(m_));
        if (m_ == 16) alpha = 0.673;
        else if (m_ == 32) alpha = 0.697;
        else if (m_ == 64) alpha = 0.709;
        alphaMM_ = alpha * static_cast<double>(m_) * static_cast<double>(m_);
    }

    void add(uint64_t item) noexcept {
        uint64_t h = hash64(item);
        uint32_t j = static_cast<uint32_t>(h >> (64 - p_));
        // Shift remaining (64 - p) bits to MSB and set sentinel bit at (p - 1)
        uint64_t w = (h << p_) | (1ULL << (p_ - 1));
        uint8_t rho = static_cast<uint8_t>(std::countl_zero(w) + 1);
        if (rho > regs_[j]) regs_[j] = rho;
    }

    double count() const noexcept {
        double sumInv = 0.0;
        uint32_t zeroRegs = 0;
        for (uint8_t r : regs_) {
            sumInv += std::ldexp(1.0, -static_cast<int>(r)); // 2^{-r}
            if (r == 0) ++zeroRegs;
        }
        double est = alphaMM_ / sumInv;
        if (est <= 2.5 * static_cast<double>(m_) && zeroRegs > 0) {
            return static_cast<double>(m_) * std::log(static_cast<double>(m_) / zeroRegs);
        }
        return est;
    }

    // Lossless Commutative Semilattice Merge (Redis PFMERGE)
    void merge(const HyperLogLog& other) noexcept {
        for (uint32_t j = 0; j < m_; ++j) {
            regs_[j] = std::max(regs_[j], other.regs_[j]);
        }
    }
};

Key Takeaways

HyperLogLog partitions a 64-bit hash into a p-bit bucket index (m = 2^p registers) and a (64-p)-bit suffix whose leading-zero rank ρ = clz(w) + 1 estimates log₂(N/m).
Aggregating the m registers via the Harmonic Mean suppresses heavy-tailed outlier variance, achieving standard error σ ≈ 1.04 / √m (0.81% with 16,384 6-bit registers in 12 KB).
For small cardinalities (E ≤ 2.5m with V > 0 empty registers), HLL transitions to LinearCounting E = m ln(m / V) to eliminate small-sample bias.
HLL sketches form a bounded join-semilattice under register-wise max(M_A[j], M_B[j]), enabling lossless O(m) distributed unions across arbitrary shards.
