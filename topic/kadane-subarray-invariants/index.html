Intuition first

Jay Kadane solved the Maximum Subarray Problem in O(N)O(N)O(N) time by asking a sharper question: instead of tracking the best subarray anywhere in A[0…i]A[0 \dots i]A[0…i], track E[i]E[i]E[i]—the maximum subarray constrained to end at index iii. Because any contiguous subarray ending at iii either extends the optimal subarray ending at i−1i-1i−1 or starts fresh at iii, E[i]E[i]E[i] satisfies the local recurrence E[i]=max⁡(A[i],E[i−1]+A[i])E[i] = \max(A[i], E[i-1] + A[i])E[i]=max(A[i],E[i−1]+A[i]), which collapses to two scalar registers.

From 2D Image Estimation to O(N)O(N)O(N) 1D Dynamic Programming

Originally posed by Ulf Grenander in 1977 for maximum-likelihood pattern detection in 2D digitized images, the Maximum Contiguous Subarray problem originally took O(N3)O(N^3)O(N3) brute force, O(N2)O(N^2)O(N2) via prefix sums, and O(Nlog⁡N)O(N \log N)O(NlogN) via divide-and-conquer before Jay Kadane (CMU) discovered the O(N)O(N)O(N) invariant in 1984. Hardware Reality: Branchless cmov Execution & Parallel Monoid Reduction

Inside Kadane's inner loop, cur_max = std::max(x, cur_max + x) and global_max = std::max(global_max, cur_max) compile on x86-64 to two additions and two conditional move (cmovg) instructions with zero branch instructions—avoiding branch predictor pollution regardless of sign oscillations. However, because cur_max depends on the previous iteration's cur_max, a single scalar Kadane loop is latency-bound by the 2-cycle integer add+cmov dependency chain. To saturate 8-wide AVX2 SIMD lanes or multi-core threads, divide the array into PPP chunks and compute the 4-tuple monoid (sum,max_prefix,max_suffix,max_subarray)(\text{sum}, \text{max\_prefix}, \text{max\_suffix}, \text{max\_subarray})(sum,max_prefix,max_suffix,max_subarray) on each chunk independently in parallel!

#include <algorithm>
#include <cstdint>
#include <vector>

struct SubarrayResult {
  std::int64_t max_sum;
  std::size_t best_left;
  std::size_t best_right;
};

// Returns maximum non-empty subarray sum along with exact [best_left, best_right] indices
SubarrayResult kadane_with_indices(const std::vector<int>& nums) noexcept {
  std::int64_t cur_sum = nums[0];
  std::int64_t max_sum = nums[0];
  std::size_t cur_left = 0, best_left = 0, best_right = 0;

  for (std::size_t i = 1; i < nums.size(); ++i) {
    if (cur_sum < 0) {
      cur_sum = nums[i];
      cur_left = i;
    } else {
      cur_sum += nums[i];
    }
    if (cur_sum > max_sum) {
      max_sum = cur_sum;
      best_left = cur_left;
      best_right = i;
    }
  }
  return {max_sum, best_left, best_right};
}

// Single-pass O(N) Time, O(1) Space Maximum Circular Subarray
std::int64_t max_subarray_circular(const std::vector<int>& nums) noexcept {
  std::int64_t total_sum = nums[0];
  std::int64_t cur_max = nums[0], global_max = nums[0];
  std::int64_t cur_min = nums[0], global_min = nums[0];

  for (std::size_t i = 1; i < nums.size(); ++i) {
    const std::int64_t x = nums[i];
    total_sum += x;
    cur_max = std::max(x, cur_max + x);
    global_max = std::max(global_max, cur_max);
    cur_min = std::min(x, cur_min + x);
    global_min = std::min(global_min, cur_min);
  }

  // If all numbers are negative, global_max < 0 and total_sum == global_min.
  // Returning total_sum - global_min would erroneously return 0 (the empty subarray).
  if (global_max < 0) {
    return global_max;
  }
  return std::max(global_max, total_sum - global_min);
}
Production Pitfall: Initializing global_max = 0 & Maximum Product Subarray Sign Flips

Two classic bugs arise in Kadane variants:

  1. Initializing global_max = 0: When the problem requires a non-empty subarray and all elements are negative (e.g., [-8, -3, -5]), initializing global_max = 0 returns 0 instead of -3. Always initialize cur_max = global_max = A[0] and loop from index i = 1.
  2. Maximum Product Subarray: Multiplication is not monotonic under sign flips—multiplying a very negative running product by a negative number A[i]<0A[i] < 0A[i]<0 turns it into the largest positive product! For Maximum Product Subarray, you must simultaneously track both cur_max and cur_min at every step: when A[i]<0A[i] < 0A[i]<0, std::swap(cur_max, cur_min) before multiplying.

Key Takeaways

Kadane's algorithm reduces the O(N^2) subarray search to O(N) by maintaining E[i] = max(A[i], E[i-1] + A[i]), the best subarray constrained to end at index i.
In a circular array, the maximum subarray is max(Kadane_max, TotalSum - Kadane_min), guarded by returning Kadane_max when all elements are negative.
Although standard Kadane has a serial dependency, promoting each segment to the 4-tuple (sum, max_pref, max_suff, max_sub) makes the operator associative for Segment Trees and SIMD/multi-core parallelism.
Always initialize Kadane's accumulators to A[0] (not 0) when non-empty subarrays are required, and track both min and max states for Maximum Product Subarray.
