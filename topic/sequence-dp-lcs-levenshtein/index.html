Erik Demaine derives the Wagner-Fischer Edit Distance DAG, sequence alignment in computational biology, and prefix-pair subproblem spaces.

Intuition first

Every git diff, spell-checker, and DNA sequence aligner walks a 2D grid graph where moving right deletes a character from A, moving down inserts a character from B, and moving diagonally matches or substitutes characters. When one string has no duplicate characters—or few matching pairs—we can even collapse the 2D grid into a 1D Longest Increasing Subsequence problem in O(N log N) time!

1. Ukkonen's Banded Edit Distance (1985): Whenever we only care if EditDistance(A,B)≤K\text{EditDistance}(A, B) \le KEditDistance(A,B)≤K (e.g., fuzzy search or spell-checking with threshold K≪NK \ll NK≪N), any path in the alignment grid that strays further than KKK diagonals away from the main diagonal (∣i−j∣>K|i - j| > K∣i−j∣>K) must pay at least ∣i−j∣>K|i - j| > K∣i−j∣>K insertions/deletions! 2. Hunt–Szymanski LCS-to-LIS Reduction: When all elements of AAA are distinct (e.g., a permutation), mapping each character in BBB to its index in AAA transforms LCS into Longest Increasing Subsequence (LIS) in O((N+M)log⁡N)O((N + M) \log N)O((N+M)logN) time! Hardware Reality — Myers' Bit-Parallel O(NM/64)O(N M / 64)O(NM/64) Edit Distance & SETH Lower Bound

Can general Edit Distance or LCS be solved in O(N2−ϵ)O(N^{2 - \epsilon})O(N2−ϵ) time? Backurs and Indyk (STOC 2015) proved that any O(N2−ϵ)O(N^{2 - \epsilon})O(N2−ϵ) algorithm for Edit Distance or LCS would refute the Strong Exponential Time Hypothesis (SETH)! In practice, production libraries (like agrep, ripgrep, and Edlib) use Myers' Bit-Parallel Algorithm (1999), encoding the horizontal and vertical ∈{−1,0,+1}\in \{-1, 0, +1\}∈{−1,0,+1} differences along columns into 64-bit integers and computing 64 rows in O(1)O(1)O(1) bitwise ALU operations (O(NM/64)O(N M / 64)O(NM/64) time).

// 1. Wagner-Fischer Levenshtein Edit Distance in O(N*M) Time and O(min(N, M)) Space
int edit_distance_space_optimized(std::string_view a, std::string_view b) {
    if (a.size() < b.size()) std::swap(a, b);
    const int n = static_cast<int>(a.size());
    const int m = static_cast<int>(b.size());

    std::vector<int> dp(m + 1);
    for (int j = 0; j <= m; ++j) dp[j] = j;

    for (int i = 1; i <= n; ++i) {
        int prev_diag = dp[0]; // Holds dp[i - 1][j - 1]
        dp[0] = i;             // Base case dp[i][0] = i deletions
        for (int j = 1; j <= m; ++j) {
            int saved_up = dp[j];
            if (a[i - 1] == b[j - 1]) {
                dp[j] = prev_diag;
            } else {
                dp[j] = 1 + std::min({ saved_up, dp[j - 1], prev_diag });
            }
            prev_diag = saved_up;
        }
    }
    return dp[m];
}

// 2. Ukkonen's O(N * K) Banded Edit Distance (Returns distance if <= k, else k + 1)
int banded_edit_distance(std::string_view a, std::string_view b, int k) {
    const int n = static_cast<int>(a.size());
    const int m = static_cast<int>(b.size());
    if (std::abs(n - m) > k) return k + 1;

    constexpr int INF = 1'000'000'000;
    std::vector<int> prev(m + 1, INF), curr(m + 1, INF);
    for (int j = 0; j <= std::min(m, k); ++j) prev[j] = j;

    for (int i = 1; i <= n; ++i) {
        int lo = std::max(1, i - k);
        int hi = std::min(m, i + k);
        curr[lo - 1] = (lo == 1) ? i : INF;

        int row_min = curr[lo - 1];
        for (int j = lo; j <= hi; ++j) {
            int cost = (a[i - 1] == b[j - 1]) ? 0 : 1;
            curr[j] = std::min({
                prev[j] + 1,         // Delete
                curr[j - 1] + 1,     // Insert
                prev[j - 1] + cost   // Match / Substitute
            });
            row_min = std::min(row_min, curr[j]);
        }
        if (hi < m) curr[hi + 1] = INF; // Guard boundary outside band
        if (row_min > k) return k + 1;   // Early exit: entire band exceeded threshold k!
        std::swap(prev, curr);
    }
    return std::min(k + 1, prev[m]);
}

// 3. Hunt-Szymanski O((N + M) log N) LCS when elements of <code>a</code> are distinct
int lcs_distinct_via_lis(const std::vector<int>& a, const std::vector<int>& b) {
    std::unordered_map<int, int> pos_in_a;
    pos_in_a.reserve(a.size() * 2);
    for (int i = 0; i < static_cast<int>(a.size()); ++i) {
        pos_in_a[a[i]] = i;
    }
    std::vector<int> tails;
    for (int x : b) {
        auto it = pos_in_a.find(x);
        if (it == pos_in_a.end()) continue;
        int idx = it->second;
        auto lb = std::lower_bound(tails.begin(), tails.end(), idx);
        if (lb == tails.end()) tails.push_back(idx);
        else *lb = idx;
    }
    return static_cast<int>(tails.size());
}

Key Takeaways

Wagner-Fischer Edit Distance relaxes an (N+1) x (M+1) DAG where horizontal edges insert, vertical edges delete, and diagonal edges match or substitute.
When only edits up to threshold K are relevant, Ukkonen's banded DP restricts evaluation to |i - j| <= K, cutting time from O(N * M) to O(N * K).
When one sequence has distinct elements (or sparse matching pairs), Hunt-Szymanski reduces LCS to 1D Longest Increasing Subsequence in O(N log N) time.
Under SETH, no strongly subquadratic O(N^(2 - eps)) algorithm exists for general Edit Distance or LCS.
