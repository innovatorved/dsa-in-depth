Push-Relabel (Goldberg-Tarjan): Preflows, Height Functions & Highest-Label Selection

7 min read Module 5.3: Network Flow, Min-Cut & Bipartite Matching Updated Oct 23, 2026
📄 Cheat Sheet
Tim Roughgarden Lectures The Push-Relabel Algorithm for Maximum Flow — Preflows & Height Labels Watch on YouTube ↗

Explains how Goldberg and Tarjan localized network flow by relaxing conservation into preflows and guiding water downhill via vertex heights.

Intuition first

Ford-Fulkerson, Edmonds-Karp, and Dinic all maintain flow conservation at every step and search globally for $s \leadsto t$ paths to relax the capacity cut condition. In 1988, Andrew Goldberg and Robert Tarjan inverted this paradigm with Push-Relabel: what if we saturate all edges leaving $s$ immediately, allow internal nodes to temporarily hold a reservoir of excess flow $e(u) = \text{in}(u) - \text{out}(u) \ge 0$ (a preflow), and push excess locally downhill along a discrete height function $h(u)$?

By initializing $h(s) = V$ and $h(v) = 0$ for $v \ne s$, excess water flows downhill toward $t$ ($h(t) = 0$). Whenever a node with excess gets trapped in a local valley with no downhill residual neighbors, it relabels (lifts) its height to $1 + \min_{(u,v) \in E_f} h(v)$, sending excess forward to $t$ or eventually draining unusable excess back uphill to $s$!

Preflows, Valid Height Functions & Local Push/Relabel Operations

A preflow $f$ satisfies capacity constraints ($0 \le f(u,v) \le c(u,v)$) and relaxed conservation: for every $u \in V \setminus \{s\}$, the excess flow is non-negative:

$$e(u) = \sum_{v \in V} f(v, u) - \sum_{w \in V} f(u, w) \ge 0$$

A vertex $u \in V \setminus \{s, t\}$ with $e(u) > 0$ is called active (overflowing).

Formal Invariant — Valid Height Function & Absence of Augmenting Paths

A height function $h: V \to \mathbb{Z}_{\ge 0}$ is valid with respect to residual graph $G_f$ if $h(s) = V$, $h(t) = 0$, and for every residual edge $(u, v) \in E_f$ ($c_f(u, v) > 0$):

$$h(u) \le h(v) + 1 \quad (\text{No steep downhill cliff in } G_f)$$

Crucial Consequence: Because $h(s) = V$, $h(t) = 0$, and each residual edge can drop height by at most $1$, any simple path from $s$ to $t$ in $G_f$ would require at least $V$ edges—impossible in a $V$-vertex graph! Thus no $s \leadsto t$ augmenting path ever exists in $G_f$ at any point during Push-Relabel. When all active nodes reach $e(u) = 0$, the preflow is a legal flow and immediately maximum!

The Two Primitive Operations & Complexity Bounds

  • Push($u, v$): Applicable when $u$ is active ($e(u) > 0$), $c_f(u, v) > 0$, and $h(u) = h(v) + 1$ (an admissible downhill edge). Push $\Delta = \min(e(u), c_f(u, v))$ units from $u$ to $v$. A push is saturating if $\Delta = c_f(u, v)$ and nonsaturating otherwise.
  • Relabel($u$): Applicable when $u$ is active ($e(u) > 0$) and has no admissible downhill residual edges ($h(u) \le h(v)$ for all $(u, v) \in E_f$). Set $h(u) = 1 + \min_{(u, v) \in E_f} h(v)$.

Since every active node $u$ has a residual path back to $s$ (conservation of initial source push) of length $\le V - 1$ and $h(s) = V$, $h(u)$ can never exceed $2V - 1$. This bounds total relabels to $O(V^2)$, saturating pushes to $O(V E)$, and nonsaturating pushes to $O(V^2 E)$ (or $O(V^2 \sqrt{E})$ under Highest-Label Selection + Gap Heuristic).

Hardware Reality — Gap Heuristic & Global Relabeling

If relabeling vertex $u$ from height $k$ to $k' > k$ leaves zero vertices at height $k$ ($\text{count}[k] == 0$, a "gap" in the height profile), then no vertex with $k < h(w) < V$ can ever reach $t$ ($h(t) = 0$) because edges only step height by $1$! The Gap Heuristic immediately sets $h(w) = \max(h(w), V + 1)$ for all such vertices $w$, routing their excess straight back to $s$ and cutting practical runtime by an order of magnitude.

Production C++20 Implementation: Highest-Label Push-Relabel with Gap Heuristic

#include <vector>
#include <algorithm>

class PushRelabel {
public:
    struct Arc {
        int to;
        long long cap;
    };

    explicit PushRelabel(int n) : n(n), adj(n), excess(n, 0), h(n, 0), count(2 * n + 1, 0), buckets(2 * n + 1) {}

    void addEdge(int u, int v, long long cap) {
        if (u == v) return;
        adj[u].push_back(static_cast<int>(arcs.size()));
        arcs.push_back({v, cap});
        adj[v].push_back(static_cast<int>(arcs.size()));
        arcs.push_back({u, 0});
    }

    long long maxFlow(int s, int t) {
        h[s] = n;
        excess[t] = 1; // Prevent t from being added to active buckets
        count[0] = n - 1;

        for (int id : adj[s]) {
            push(s, id, arcs[id].cap);
        }

        while (maxHeight >= 0) {
            if (buckets[maxHeight].empty()) {
                --maxHeight;
                continue;
            }
            int u = buckets[maxHeight].back();
            buckets[maxHeight].pop_back();
            discharge(u, s, t);
        }
        return excess[t] - 1;
    }

private:
    int n, maxHeight = 0;
    std::vector<Arc> arcs;
    std::vector<std::vector<int>> adj;
    std::vector<long long> excess;
    std::vector<int> h, count;
    std::vector<std::vector<int>> buckets;

    void push(int u, int id, long long d) {
        if (d == 0) return;
        int v = arcs[id].to;
        if (excess[v] == 0 && h[v] < n) {
            buckets[h[v]].push_back(v);
            maxHeight = std::max(maxHeight, h[v]);
        }
        arcs[id].cap -= d;
        arcs[id ^ 1].cap += d;
        excess[u] -= d;
        excess[v] += d;
    }

    void discharge(int u, int s, int t) {
        while (excess[u] > 0) {
            int minNeighborH = 2 * n;
            for (int id : adj[u]) {
                if (arcs[id].cap == 0) continue;
                int v = arcs[id].to;
                if (h[u] == h[v] + 1) {
                    push(u, id, std::min(excess[u], arcs[id].cap));
                    if (excess[u] == 0) return;
                } else {
                    minNeighborH = std::min(minNeighborH, h[v]);
                }
            }
            // Relabel with Gap Heuristic
            int oldH = h[u];
            --count[oldH];
            if (count[oldH] == 0 && oldH < n) {
                for (int i = 0; i < n; ++i) {
                    if (i != s && i != t && h[i] > oldH && h[i] <= n) {
                        --count[h[i]];
                        h[i] = n + 1;
                    }
                }
            }
            h[u] = minNeighborH + 1;
            ++count[h[u]];
            if (h[u] >= n) return; // Excess will drain back to s in phase 2 or can be ignored for maxFlow value
        }
    }
};
Failure Mode — Reading Edge Flows Before Phase-2 Excess Drainage

When only the scalar value $|f^*| = e(t)$ is needed, nodes lifted to $h(u) \ge V$ can stop discharging because their excess can never reach $t$. However, if you need the actual per-edge flow assignment $f(u, v)$ (satisfying strict flow conservation $e(u) = 0$ everywhere), you must continue discharging nodes with $V \le h(u) < 2V$ until all remaining excess drains back into $s$.

Suppose relabeling vertex $u$ away from height $k$ ($0 < k < V$) leaves **zero** vertices with height $k$ (`count[k] == 0`). Why can the Gap Heuristic immediately lift every vertex $w$ with $k < h(w) < V$ to height $V + 1$?

With no vertex at height k, no path in G_f can bridge from height > k to height < k. Thus vertices with h(w) > k can never reach t and represent the source side S of the min-cut.

Cheriyan & Maheshwari (1989) and Tunçel (1994) proved that discharging the highest active vertex bounds nonsaturating pushes to O(V^2 sqrt(E)), making Highest-Label + Gap Heuristic the fastest max-flow solver on dense benchmarks.

Key Takeaways

Push-Relabel relaxes flow conservation into a preflow (e(u) >= 0) while strictly maintaining the cut validity invariant h(u) <= h(v) + 1 in G_f.
Because h(s) = V and h(t) = 0, no augmenting path from s to t ever exists in G_f during Push-Relabel.
Vertex heights never exceed 2V - 1, bounding total relabels to O(V^2) and saturating pushes to O(V E).
Selecting the active node with the maximum height (Highest-Label) combined with the Gap Heuristic achieves O(V^2 sqrt(E)) time.
