Explains how industrial SAT solvers scale from 100 variables to millions of variables using Two-Watched Literals and Conflict-Driven Clause Learning.

Intuition first

Every time you run cargo build, apt-get install, or conda install, a SAT/PubGrub solver resolves thousands of conflicting version ranges in milliseconds. The secret that separates a toy recursive backtracker from an industrial SAT solver (MiniSat, CaDiCaL, Z3) is Unit Propagation (BCP), the Two-Watched Literals invariant (which needs zero pointer updates on backtrack!), and Conflict-Driven Clause Learning (CDCL).

1. From Naive Backtracking to DPLL & Boolean Constraint Propagation (BCP)

A Boolean formula in Conjunctive Normal Form (CNF) is an AND (∧\wedge∧) of clauses, where each clause is an OR (∨\vee∨) of literals (xix_ixi​ or ¬xi\neg x_i¬xi​). Package managers encode dependencies directly as CNF clauses:

  • pkgA@1.2 requires pkgB@2.0 or pkgB@2.1   ⟹  (¬A1.2∨B2.0∨B2.1)\implies (\neg A_{1.2} \vee B_{2.0} \vee B_{2.1})⟹(¬A1.2​∨B2.0​∨B2.1​).
  • pkgB@2.0 conflicts with pkgB@2.1   ⟹  (¬B2.0∨¬B2.1)\implies (\neg B_{2.0} \vee \neg B_{2.1})⟹(¬B2.0​∨¬B2.1​).

The DPLL Algorithm (Davis–Putnam–Logemann–Loveland, 1962) enhances backtracking with Unit Propagation (Boolean Constraint Propagation / BCP): Whenever all literals in a clause except one are assigned FALSE, the remaining unassigned literal lll is a unit clause and must be assigned TRUE immediately. Assigning l=TRUEl = \text{TRUE}l=TRUE may create new unit clauses in a cascade (fixed-point queue) before any branching decision is made.

Core Invariant — Chaff's Two-Watched Literals (2WL) Invariant

In a naive DPLL solver, checking whether an assignment makes a clause unit requires maintaining a counter of unassigned literals in every clause containing ¬l\neg l¬l, and decrementing/incrementing all those counters on every step and every backtrack.
Instead, Two-Watched Literals (Moskewicz et al., Chaff 2001) watches only two literals w1,w2w_1, w_2w1​,w2​ in each clause CCC (with ∣C∣≥2|C| \ge 2∣C∣≥2), maintaining the invariant: As long as the clause is not already satisfied, neither w1w_1w1​ nor w2w_2w2​ is assigned FALSE.
Consequently, a clause can never become a unit clause or falsified unless one of its two watched literals becomes FALSE! Better yet: when backtracking (unassigning variables), w1w_1w1​ and w2w_2w2​ remain valid watches—backtracking requires ZERO watch-list updates (O(1)O(1)O(1) time)!

2. How Two-Watched Literals & CDCL Work Together

When literal lll is assigned TRUE, its negation ¬l\neg l¬l becomes FALSE. We inspect only the watch list watches[~l]. For each clause CCC watching ¬l\neg l¬l (with other watch wotherw_{other}wother​):

  1. If wotherw_{other}wother​ is already TRUE, CCC is satisfied—do nothing.
  2. Scan the non-watched literals of CCC for any literal lnewl_{new}lnew​ that is not FALSE. If found, replace watch ¬l\neg l¬l with lnewl_{new}lnew​ and move CCC to watches[l_new] (no propagation needed).
  3. If all non-watched literals are FALSE:
    • If wotherw_{other}wother​ is FALSE, CCC is a Conflict Clause (all literals FALSE)—trigger conflict analysis / backtrack!
    • If wotherw_{other}wother​ is UNASSIGNED, CCC is now a Unit Clause—enqueue wother=TRUEw_{other} = \text{TRUE}wother​=TRUE into the BCP trail!

In modern CDCL (Conflict-Driven Clause Learning) solvers, when a conflict occurs, the solver resolves the conflict along the implication graph to learn a new conflict clause (a nogood) and performs a non-chronological backjump directly to the decision level responsible for the conflict.

Hardware Reality — Why 80% of SAT Solver CPU Time Is Spent in propagate()

Empirical profiling of MiniSat and CaDiCaL shows that 80%–90% of total runtime is spent scanning watches[~l] inside Boolean Constraint Propagation. Because Two-Watched Literals never touches watch lists during backtracking, unassigning 1,000 variables on backtrack is a simple array index reset trail_head = level_pos[lvl]! Furthermore, industrial solvers inline the blocker literal (wotherw_{other}wother​) directly inside the 8-byte watch-list entry struct Watch { int clause_id; int blocker; } so if blocker is already TRUE, the CPU skips dereferencing the clause pointer entirely—saving an L3 cache miss.

4. Reference C++20 Implementation

C++20103 lines
#include <cstdint>
#include <vector>

// Compact DPLL SAT Solver with Unit Propagation and Trail-Based Undo
// Literals for variable v in [0..n-1] are encoded as: pos = 2*v, neg = 2*v ^ 1
class DpllSatSolver {
    int num_vars;
    std::vector<std::vector<int>> clauses;
    std::vector<std::vector<int>> watches; // watches[lit] = list of clause IDs watching <code>lit</code>
    std::vector<std::int8_t> val;          // -1: unassigned, 0: false, 1: true (indexed by literal)
    std::vector<int> trail;                // Stack of assigned literals
    int qhead = 0;                         // BCP queue pointer inside <code>trail</code>

    bool enqueue(int lit) {
        if (val[lit] == 1) return true;    // Already satisfied
        if (val[lit] == 0) return false;   // Conflict!
        val[lit] = 1;
        val[lit ^ 1] = 0;
        trail.push_back(lit);
        return true;
    }

    // Boolean Constraint Propagation (BCP) using Two-Watched Literals
    bool propagate() {
        while (qhead < static_cast<int>(trail.size())) {
            int falsified_lit = trail[qhead++] ^ 1; // ~lit just became FALSE
            auto& wl = watches[falsified_lit];
            std::size_t j = 0;
            for (std::size_t i = 0; i < wl.size(); ++i) {
                int cid = wl[i];
                auto& c = clauses[cid];
                // Ensure c[1] is the falsified watched literal, c[0] is the other watch
                if (c[0] == falsified_lit) std::swap(c[0], c[1]);

                if (val[c[0]] == 1) { // Other watch is already TRUE -> clause satisfied
                    wl[j++] = cid;
                    continue;
                }
                // Try to find a replacement watch in c[2..end] that is not FALSE
                bool moved = false;
                for (std::size_t k = 2; k < c.size(); ++k) {
                    if (val[c[k]] != 0) {
                        std::swap(c[1], c[k]);
                        watches[c[1]].push_back(cid);
                        moved = true;
                        break;
                    }
                }
                if (moved) continue; // Watch moved to c[1]; do NOT keep cid in wl

                // No replacement found: keep watching falsified_lit and unit-propagate c[0]
                wl[j++] = cid;
                if (!enqueue(c[0])) {
                    while (++i < wl.size()) wl[j++] = wl[i];
                    wl.resize(j);
                    return false; // Conflict!
                }
            }
            wl.resize(j);
        }
        return true;
    }

    void backtrack_to(int trail_pos) {
        while (static_cast<int>(trail.size()) > trail_pos) {
            int lit = trail.back();
            val[lit] = -1;
            val[lit ^ 1] = -1;
            trail.pop_back();
        }
        qhead = trail_pos; // Notice: ZERO watch-list updates required on backtrack!
    }

public:
    explicit DpllSatSolver(int n) : num_vars(n), watches(2 * n), val(2 * n, -1) {}

    bool add_clause(std::vector<int> lits) {
        if (lits.empty()) return false;
        if (lits.size() == 1) return enqueue(lits[0]) && propagate();
        int cid = static_cast<int>(clauses.size());
        watches[lits[0]].push_back(cid);
        watches[lits[1]].push_back(cid);
        clauses.push_back(std::move(lits));
        return true;
    }

    bool solve() {
        if (!propagate()) return false;
        // Find first unassigned variable
        int branch_var = -1;
        for (int v = 0; v < num_vars; ++v) {
            if (val[2 * v] == -1) { branch_var = v; break; }
        }
        if (branch_var == -1) return true; // All variables assigned without conflict -> SAT!

        int saved_pos = static_cast<int>(trail.size());
        for (int polarity : {0, 1}) {
            if (enqueue(2 * branch_var ^ polarity) && solve()) return true;
            backtrack_to(saved_pos);
        }
        return false;
    }
};

Production Pitfall — Corrupting the Watch Vector While Iterating Over watches[~l]

Inside propagate(), when a conflict occurs mid-loop while compacting watches[falsified_lit] in-place from index i to index j, if you return false immediately without copying the remaining untouched elements wl[i+1..end] down to wl[j..] and resizing, you will permanently lose watch entries for the rest of the clauses! Always finish compacting the tail of wl before returning on conflict.

Concept Check Blocker Literal Cache Optimization in Production SAT Solvers staff

Why do industrial CDCL solvers (such as MiniSat and CaDiCaL) store a `blocker` literal directly inside each 8-byte entry `{ clause_id, blocker }` of the `watches[lit]` vector?

In large SAT instances with millions of clauses, dereferencing `clauses[clause_id]` chases a pointer into a huge clause arena, incurring an L3/DRAM cache miss. Checking `val[blocker] == TRUE` (where `blocker` is typically the other watched literal c[0]c[0]c[0]) inside the contiguous watch vector avoids touching the clause memory altogether whenever the clause is already satisfied.

Key Takeaways

DPLL combines backtracking search with Boolean Constraint Propagation (BCP): any clause with a single unassigned literal forces that literal to TRUE.
Two-Watched Literals (2WL) watches only 2 non-falsified literals per clause, ensuring watch lists only update when a watched literal becomes FALSE.
Because watched literals remain valid when variables become unassigned, backtracking under 2WL requires zero watch-list modifications (O(1) per variable).
Package managers (Cargo, APT, Conda) encode version dependencies and conflicts as SAT clauses and use unit propagation + conflict clause learning (CDCL/PubGrub).
