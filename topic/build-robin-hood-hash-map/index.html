Intuition first

In this Build Lab, we engineer a complete, zero-dependency, production-grade Open-Addressed Robin Hood Hash Map in C++20 (RobinHoodMap<K, V>). Unlike naive linear-probing tables that degrade over time as TOMBSTONE markers accumulate from deletions, our engine maintains explicit Probe Sequence Length (psl) metadata per slot, enforces the Robin Hood displacement invariant on insertion, uses PSL early-exit on unsuccessful searches, and executes Tombstone-Free Backward-Shift Deletion on erase(key).

Architecture & Invariant Specifications

Our implementation guarantees four structural invariants across every insert, find, erase, and rehash operation:

  1. Power-of-Two Capacity ($m = 2^r$) with SplitMix64 Finalizer: Every key is mixed through a 64-bit SplitMix64 avalanche permutation so both high and low bits have full entropy, and bucket indexing uses a single bitwise AND idx = hash & (m - 1).
  2. 1-Based Distance-from-Initial-Bucket (dib = psl + 1): Instead of storing both a bool occupied flag and a uint32_t psl counter, we store a single integer dib (Distance from Initial Bucket): dib == 0 denotes an EMPTY slot, while dib >= 1 denotes an occupied slot with $\text{PSL} = \text{dib} - 1$.
  3. Robin Hood Swap Invariant (curr_dib > slot.dib): During insert, if an occupied slot has the same key, we update its value in-place; otherwise if curr_dib > slot.dib, the incoming entry steals the slot via std::swap and continues probing with the displaced entry.
  4. Backward-Shift Deletion (erase): When deleting at idx, we inspect next = (idx + 1) & mask. While table[next].dib > 1 (meaning the occupant at next is occupied AND displaced from its home bucket, i.e., $\text{PSL} > 0$), we shift table[next] backward to table[idx] with dib - 1 and advance idx = next. Finally, we clear table[idx].dib = 0.

Formal Proof: Correctness of Backward-Shift Deletion Without Tombstones

Suppose slot $i$ is deleted. Let $C = [i+1, i+2, \dots, i+L]$ (modulo $m$) be the maximal contiguous run of slots immediately following $i$ whose occupants satisfy $\text{dib} > 1$ (equivalently $\text{PSL} \ge 1$). For every key $k \in C$, its home bucket $h(k)$ lies at or before $i$ along the cluster, so $k$ originally probed across slot $i$. Shifting every key in $C$ backward by $1$ slot and decrementing its dib by $1$ moves each key $1$ step closer to its home bucket $h(k)$, preserving the Robin Hood ordering invariant $\text{dib}[j+1] \le \text{dib}[j] + 1$ and leaving slot $i + L$ safely EMPTY (dib = 0) because slot $i + L + 1$ either is EMPTY or holds a key at its exact home bucket (dib == 1).

Hardware Reality: Cached Hash Comparison Before Full Key Equality

When keys are strings (std::string) or composite structs, calling slot.key == key dereferences a heap pointer and runs memcmp. By caching the 32-bit or 64-bit hash inside the slot (or comparing slot.dib == dib first, since two keys at the same slot index idx have the exact same home bucket $(idx - (\text{dib}-1)) \bmod m$ if and only if their dib values are equal!), we reject $> 99\%$ of non-matching slots in registers without ever touching the string heap buffer.

Complete Reference Implementation: RobinHoodMap<K, V> in C++20

// C++20: Complete Open-Addressed Robin Hood Hash Table with Tombstone-Free Backward Shift
#include <vector>
#include <cstdint>
#include <optional>
#include <utility>
#include <algorithm>

template <typename K, typename V>
class RobinHoodMap {
    struct Slot {
        K key{};
        V val{};
        uint32_t dib = 0; // 0 = EMPTY, >= 1 means PSL = dib - 1
    };

    std::vector<Slot> table_;
    size_t size_ = 0;

    static uint64_t hashKey(const K& k) noexcept {
        uint64_t x = static_cast<uint64_t>(std::hash<K>{}(k));
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
        x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
        return x ^ (x >> 31);
    }

    void rehash(size_t newCap) {
        std::vector<Slot> old = std::move(table_);
        table_.assign(newCap, Slot{});
        size_ = 0;
        for (auto& s : old) {
            if (s.dib > 0) insert(std::move(s.key), std::move(s.val));
        }
    }

public:
    explicit RobinHoodMap(size_t initialPow2Cap = 16) : table_(initialPow2Cap) {}

    size_t size() const noexcept { return size_; }

    bool insert(K key, V val) {
        // Resize at 85% load factor (17/20)
        if ((size_ + 1) * 20 >= table_.size() * 17) {
            rehash(table_.size() * 2);
        }
        const size_t mask = table_.size() - 1;
        size_t idx = hashKey(key) & mask;
        uint32_t curDib = 1;

        while (true) {
            Slot& s = table_[idx];
            if (s.dib == 0) {
                s.key = std::move(key);
                s.val = std::move(val);
                s.dib = curDib;
                ++size_;
                return true;
            }
            if (s.dib == curDib && s.key == key) {
                s.val = std::move(val); // Update existing key in-place
                return false;
            }
            // Robin Hood Rule: steal slot if incoming key has larger DIB than occupant
            if (curDib > s.dib) {
                std::swap(key, s.key);
                std::swap(val, s.val);
                std::swap(curDib, s.dib);
            }
            idx = (idx + 1) & mask;
            ++curDib;
        }
    }

    std::optional<V> find(const K& key) const {
        const size_t mask = table_.size() - 1;
        size_t idx = hashKey(key) & mask;
        uint32_t curDib = 1;

        while (true) {
            const Slot& s = table_[idx];
            // Early-exit invariant: if slot is empty OR occupant is richer, key cannot exist
            if (s.dib < curDib) return std::nullopt;
            if (s.dib == curDib && s.key == key) return s.val;
            idx = (idx + 1) & mask;
            ++curDib;
        }
    }

    bool erase(const K& key) {
        const size_t mask = table_.size() - 1;
        size_t idx = hashKey(key) & mask;
        uint32_t curDib = 1;

        while (true) {
            Slot& s = table_[idx];
            if (s.dib < curDib) return false; // Key not found
            if (s.dib == curDib && s.key == key) break; // Located target at idx
            idx = (idx + 1) & mask;
            ++curDib;
        }

        // Tombstone-free backward shift deletion
        size_t next = (idx + 1) & mask;
        while (table_[next].dib > 1) {
            table_[idx] = std::move(table_[next]);
            --table_[idx].dib;
            idx = next;
            next = (next + 1) & mask;
        }
        table_[idx] = Slot{};
        --size_;
        return true;
    }

    uint32_t maxPsl() const noexcept {
        uint32_t maxD = 1;
        for (const auto& s : table_) maxD = std::max(maxD, s.dib);
        return maxD - 1;
    }
};

Failure Modes & Adversarial Pitfalls

  • Checking s.key == key After Swapping Before Checking Duplicate Key: Notice that when s.dib == curDib, both keys share the exact same home bucket (idx - (curDib - 1)). If s.dib < curDib, the incoming key could never be a duplicate of s.key (nor of any key later in the cluster, since later keys have strictly larger home buckets). Thus checking if (s.dib == curDib && s.key == key) before the if (curDib > s.dib) swap guarantees no duplicate key is ever inserted!
  • Using Unmixed Identity Hashes with Power-of-Two Masking: Always pass std::hash<K> through a 64-bit finalizer (SplitMix64) so lower bits used by & (m - 1) reflect all 64 bits of the key.

Concept Check Swapping All State During a Robin Hood Eviction recall

In your `RobinHoodMap::insert` loop, the incoming candidate has `dist = 3` and encounters an occupied slot at `idx` whose resident element has `slots_[idx].psl = 1`.

The displaced key is ALREADY `slots_[idx].psl` steps away from its own home bucket! When it gets evicted to `idx + 1`, its distance from its home bucket becomes `old_psl + 1`. Therefore you must swap `dist` with `slots_[idx].psl` (storing the incoming element's `dist = 3` into the slot and loading the displaced element's `1` into `dist`), and then increment `dist++` as `idx` advances.
Concept Check Tracing Backward-Shift Deletion Across Cluster Boundaries apply

Consider a 8-slot Robin Hood table (`mask_ = 7`) where indices 2, 3, 4, and 5 are occupied with `(key, home, psl)` equal to: Slot 2: `(A, 2, 0)`, Slot 3: `(B, 2, 1)`, Slot 4: `(C, 4, 0)`, Slot 5: `(D, 3, 2)`.

Wait—let's check the Robin Hood invariant on the initial state! In a valid Robin Hood table, could Slot 4 have (C,4,0) while Slot 5 has (D,3,2)? No! Because when D (home=3) probed through Slot 4 (where D had dist=1 and C had psl=0), D would have evicted C from Slot 4! Thus in a valid Robin Hood table, if Slot 4 has psl=0, no element at Slot 5 can have a home ≤ 4. Consequently, backward shift at `erase(A)` shifts Slot 3 (B, psl=1 → 0) into Slot 2, then inspects Slot 4 (`C.psl == 0`), and immediately terminates, marking Slot 3 empty.
Concept Check Early-Exit Lookup Condition in Robin Hood Hashing apply

You call `find(k)` on a `RobinHoodMap`. The key hashes to home index `idx = 10` (`dist = 0`). Slot 10 is occupied by another key with `psl = 2`. Slot 11 is occupied by another key with `psl = 3`. Slot 12 is occupied by another key with `psl = 1`.

At Slot 10, `dist = 0 ≤ psl = 2` (continue). At Slot 11, `dist = 1 ≤ psl = 3` (continue). At Slot 12, our search candidate is at `dist = 2` from its home (10), whereas the resident of Slot 12 is only at `psl = 1` from its home (11). By the Robin Hood invariant, a key with `dist = 2` would have evicted a key with `psl = 1` at Slot 12. Hence `k` cannot exist anywhere in the table, and `find` returns `nullptr` without scanning the rest of the cluster.
Concept Check Why Store 1-Indexed PSL (0 = Empty) Instead of a Separate `bool occupied` + `uint32_t psl` staff

In the build lab, each `Slot` stores `uint8_t psl` where `0` means empty and `d >= 1` means occupied with Probe Sequence Length $d - 1$, rather than `bool occupied; size_t psl;`.

With `dist` starting at `1` (1-indexed PSL) and `psl == 0` representing an empty slot, the condition `dist > slots_[idx].psl` is simultaneously true for BOTH an empty slot (`dist >= 1 > 0`) AND a wealthier resident (`dist > resident_psl`)! This eliminates a separate branch for `if (!slot.occupied)` in the lookup early-exit and cuts metadata footprint from 16 bytes down to 1 byte.

Key Takeaways

Encoding DIB = PSL + 1 (with DIB = 0 for empty slots) unifies occupancy and probe distance in a single integer field.
Two entries at index idx share the same home bucket if and only if their DIB values are equal, enabling a zero-cost integer pre-check (s.dib == curDib) before full key comparison.
Early-exit lookup stops immediately whenever s.dib < curDib, bounding unsuccessful search probes tightly around the mean.
Backward-shift deletion shifts subsequent entries with DIB > 1 left by one slot and decrements their DIB, maintaining 0 tombstones across infinite insert/delete churn.
