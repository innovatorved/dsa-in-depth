Build Lab: Generic Lazy-Propagating Segment Tree with Range Affine Updates & Queries

7 min read Module 3.3: Range Query & Sublinear Decomposition Structures Updated Oct 21, 2026
📄 Cheat Sheet
SecondThread AlgorithmsThread 3: Segment Trees & Lazy Propagation Watch on YouTube ↗

Walks through composing affine lazy tags f(x) = a*x + b so range assignment, range scaling, and range addition unify into a single bug-free lazy segment tree.

Intuition first

In interviews and production analytics engines, the hardest lazy segment tree bug occurs when a problem combines multiple range update types—such as rangeAdd(l, r, b), rangeScale(l, r, a), and rangeAssign(l, r, c)—alongside range queries like rangeSum(l, r), rangeMin(l, r), and maxRight(l, pred). Maintaining separate boolean flags and + "addTag" + / + "setTag" + fields leads to a tangle of 8+ conditional branches inside + "pushDown" + .

Instead, notice that all three range updates are special cases of a single Range Affine Transformation $f(x) = a \cdot x + b$!

  • rangeAdd(l, r, delta) is the affine map $(a = 1, b = \text{delta})$.
  • rangeScale(l, r, factor) is the affine map $(a = \text{factor}, b = 0)$.
  • rangeAssign(l, r, val) is the affine map $(a = 0, b = \text{val})$ (multiplying old values by $0$ and adding $\text{val}$)!
Composing a new tag $f_{\text{new}}(x) = a_2 x + b_2$ onto an existing pending tag $f_{\text{old}}(x) = a_1 x + b_1$ is simply $f_{\text{new}}(f_{\text{old}}(x)) = (a_2 a_1)x + (a_2 b_1 + b_2)$, with identity tag $(1, 0)$! In this Build Lab, we engineer both an specialized SoA Range Affine Lazy Segment Tree and a generic AtCoder-style Monoid + Homomorphism Lazy Segment Tree supporting $O(\log N)$ binary search ( + "maxRight" + ).

1. Algebraic Specification of the Range Affine Lazy Segment Tree

Let each node $v$ covering $[tl, tr]$ of length $\text{len} = tr - tl + 1$ store:

  • Data Summary: $\text{sum}[v] = \sum_{i=tl}^{tr} A[i]$.
  • Lazy Affine Tag: $(\text{lazyA}[v], \text{lazyB}[v])$, initialized to the identity map $(1, 0)$.
Affine Tag Application & Composition Invariants: When applying affine tag $(a, b)$ to node $v$ of length $\text{len} = tr - tl + 1$:
  1. Summary Update: $\sum_{i=tl}^{tr} (a \cdot A[i] + b) = a \cdot \text{sum}[v] + b \cdot \text{len}$.
  2. Tag Composition ($f_{\text{new}} \circ f_{\text{old}}$): If $v$ already holds pending tag $(a_1, b_1)$, applying $(a_2, b_2)$ updates the tag to: $$\text{lazyA}[v] \leftarrow a_2 \cdot a_1, \qquad \text{lazyB}[v] \leftarrow a_2 \cdot b_1 + b_2$$ Notice that when $a_2 = 0$ (rangeAssign(l, r, c)), this automatically zeroes out $a_1$ and $b_1$, leaving $(0, c)$ with zero if/else branching!
flowchart TD MR["maxRight(v, tl, tr, l, pred, acc)"] --> Out{"tr < l?"} Out -- Yes --> RetTr["Return tr (before l)"] Out -- No --> Inside{"tl >= l AND pred(combine(acc, sum[v]))?"} Inside -- Yes --> Consume["acc = combine(acc, sum[v]) Return tr (consume whole subtree O(1)!)"] Inside -- No --> Leaf{"tl == tr?"} Leaf -- Yes --> Stop["Return tl - 1 (boundary reached)"] Leaf -- No --> Push["pushDown(v); recurse Left; if Left fully consumed, recurse Right"]
Hardware & Cache Reality — Why Tree-Walk maxRight Beats Binary Search + Query by $O(\log N)$: Calling binary search over rangeSum(l, mid) performs $\log_2 N$ segment tree queries, each taking $O(\log N)$ time ($O(\log^2 N)$ total, ~400 node visits for $N = 10^5$). By descending directly inside the Segment Tree while maintaining a running accumulator acc, maxRight(l, pred) consumes at most $O(\log N)$ whole canonical subtrees in $O(1)$ each and descends down at most one leaf path where pred(combine(acc, sum[v])) first turns false—visiting at most $4 \log_2 N \approx 68$ nodes total!

2. Complete Production Implementation: Range Affine Lazy Segment Tree + Verification Suite

JAVASCRIPT
/**
 * Production Range Affine Lazy Segment Tree (Struct-of-Arrays TypedArray Layout)
 * Supports:
 *  - rangeAffine(ql, qr, a, b): for i in [ql..qr], A[i] = a * A[i] + b in O(log N)
 *  - rangeAdd(ql, qr, delta):   special case rangeAffine(ql, qr, 1, delta)
 *  - rangeScale(ql, qr, k):     special case rangeAffine(ql, qr, k, 0)
 *  - rangeAssign(ql, qr, val):  special case rangeAffine(ql, qr, 0, val)
 *  - rangeSum(ql, qr):          sum of A[ql..qr] in O(log N)
 *  - maxRight(l, pred):         largest r >= l-1 such that pred(sum(l..r)) is true in O(log N)
 */
class RangeAffineLazySegTree {
  constructor(arr) {
    this.n = arr.length;
    const size = 4 * this.n;
    this.sum = new Float64Array(size);
    this.lazyA = new Float64Array(size).fill(1);
    this.lazyB = new Float64Array(size).fill(0);
    if (this.n > 0) this._build(1, 0, this.n - 1, arr);
  }

  _build(v, tl, tr, arr) {
    if (tl === tr) {
      this.sum[v] = arr[tl];
      return;
    }
    const tm = (tl + tr) >> 1;
    this._build(v << 1, tl, tm, arr);
    this._build((v << 1) | 1, tm + 1, tr, arr);
    this.sum[v] = this.sum[v << 1] + this.sum[(v << 1) | 1];
  }

  _apply(v, len, a, b) {
    this.sum[v] = a * this.sum[v] + b * len;
    this.lazyA[v] = a * this.lazyA[v];
    this.lazyB[v] = a * this.lazyB[v] + b;
  }

  _pushDown(v, tl, tr) {
    const a = this.lazyA[v], b = this.lazyB[v];
    if (a === 1 && b === 0) return;
    const tm = (tl + tr) >> 1;
    this._apply(v << 1, tm - tl + 1, a, b);
    this._apply((v << 1) | 1, tr - tm, a, b);
    this.lazyA[v] = 1;
    this.lazyB[v] = 0;
  }

  rangeAffine(ql, qr, a, b, v = 1, tl = 0, tr = this.n - 1) {
    if (ql > tr || qr < tl) return;
    if (ql <= tl && tr <= qr) {
      this._apply(v, tr - tl + 1, a, b);
      return;
    }
    this._pushDown(v, tl, tr);
    const tm = (tl + tr) >> 1;
    this.rangeAffine(ql, qr, a, b, v << 1, tl, tm);
    this.rangeAffine(ql, qr, a, b, (v << 1) | 1, tm + 1, tr);
    this.sum[v] = this.sum[v << 1] + this.sum[(v << 1) | 1];
  }

  rangeAdd(ql, qr, delta) {
    this.rangeAffine(ql, qr, 1, delta);
  }

  rangeScale(ql, qr, factor) {
    this.rangeAffine(ql, qr, factor, 0);
  }

  rangeAssign(ql, qr, val) {
    this.rangeAffine(ql, qr, 0, val);
  }

  rangeSum(ql, qr, v = 1, tl = 0, tr = this.n - 1) {
    if (ql > tr || qr < tl) return 0;
    if (ql <= tl && tr <= qr) return this.sum[v];
    this._pushDown(v, tl, tr);
    const tm = (tl + tr) >> 1;
    return (
      this.rangeSum(ql, qr, v << 1, tl, tm) +
      this.rangeSum(ql, qr, (v << 1) | 1, tm + 1, tr)
    );
  }

  /**
   * Single-pass O(log N) Segment Tree Walk (requires non-negative elements for monotone sum):
   * Returns largest index r in [l-1 .. n-1] such that pred(sum(l..r)) === true.
   */
  maxRight(l, pred) {
    let acc = 0;
    const walk = (v, tl, tr) => {
      if (tr < l) return tr;
      if (tl >= l && pred(acc + this.sum[v])) {
        acc += this.sum[v];
        return tr;
      }
      if (tl === tr) return tl - 1;
      this._pushDown(v, tl, tr);
      const tm = (tl + tr) >> 1;
      const resL = walk(v << 1, tl, tm);
      if (resL < tm) return resL; // Stopped inside left child!
      return walk((v << 1) | 1, tm + 1, tr);
    };
    return walk(1, 0, this.n - 1);
  }
}

Common Pitfall — Forgetting to Multiply $b$ by Segment Length len = tr - tl + 1: When applying an affine tag $(a, b)$ to a single element $x$, the new value is $ax + b$. When applying $(a, b)$ to a segment sum $\text{sum}[v] = \sum_{i=tl}^{tr} A[i]$ covering $\text{len} = tr - tl + 1$ elements, the additive constant $b$ is added to every one of the $\text{len}$ elements, so $\text{sum}[v] \leftarrow a \cdot \text{sum}[v] + b \cdot \text{len}$! However, when composing the lazy tag lazyB[v] = a * lazyB[v] + b, you do not multiply $b$ by len because lazyB[v] is a per-element affine coefficient that will be multiplied by child lengths when pushed down.

Concept Check Expressing Range Assignment as an Affine Transformation recall

In a Range Affine Lazy Segment Tree where each lazy tag $(a, b)$ transforms every element $x \leftarrow a \cdot x + b$, how are `rangeAdd(l, r, d)`, `rangeScale(l, r, k)`, and `rangeAssign(l, r, c)` represented as pairs $(a, b)$?

Applying (1, d) computes 1*x + d = x + d (add). Applying (k, 0) computes k*x + 0 = k*x (scale). Applying (0, c) computes 0*x + c = c (overwriting any previous value x with c!). And (1, 0) computes 1*x + 0 = x (identity).
Concept Check Composing Two Affine Lazy Tags (`f_new` After `f_old`) apply

Suppose node $v$ in a Range Affine Lazy Segment Tree already holds a pending lazy tag $(a_1, b_1)$ representing $f_{\text{old}}(x) = a_1 x + b_1$, and a new range update applies $(a_2, b_2)$ representing $f_{\text{new}}(y) = a_2 y + b_2$ to node $v$.

Substituting y = f_old(x) = a1 * x + b1 into f_new(y) = a2 * y + b2 gives a2 * (a1 * x + b1) + b2 = (a2 * a1) * x + (a2 * b1 + b2). Notice that function composition is NOT commutative: the new multiplier a2 scales BOTH the old multiplier a1 AND the old additive offset b1!
Concept Check Updating Node Summary vs Lazy Offset with Segment Length `len` apply

When applying affine tag $(a, b)$ to a segment tree node $v$ covering $[tl, tr]$ of length $\text{len} = tr - tl + 1$, how do `sum[v]` and `lazyB[v]` incorporate the segment length `len`?

Summing `a * A[i] + b` over `i = tl .. tr` yields `a * sum[v] + b * (tr - tl + 1)`. However, the lazy tag `(lazyA[v], lazyB[v])` represents the per-element function `f(x) = A * x + B` that will later be pushed down to `v`'s children; multiplying `b` by `len` inside `lazyB[v]` would multiply by length twice when pushed down!
Concept Check Single-Pass O(log N) `maxRight(l, pred)` Complexity Proof staff

In the `maxRight(l, pred)` method on a Lazy Segment Tree, we want to find the largest index $r \ge l - 1$ such that `pred(sum(l..r))` is true (assuming `pred` is monotone, e.g., `sum <= K` on non-negative elements).

Just like a normal segment tree range query decomposes `[l, N-1]` into O(log N) canonical nodes along the left boundary `l`, `maxRight` tests each of those O(log N) canonical nodes in left-to-right order: all canonical nodes before the threshold `r*` satisfy `pred(acc + sum[v]) === true` and are absorbed in O(1) time (`acc += sum[v]; return tr;`). The FIRST canonical node where `pred(acc + sum[v]) === false` contains `r*`, and the algorithm walks down a single root-to-leaf path inside that node to pinpoint `r*` and immediately terminates!

Key Takeaways

Representing range updates as affine functions f(x) = a*x + b unifies rangeAdd (1, d), rangeScale (k, 0), and rangeAssign (0, c) under a single branchless composition rule.
Composing a new affine tag (a2, b2) onto an existing tag (a1, b1) yields (a2 * a1, a2 * b1 + b2), with identity (1, 0).
When updating node v's range sum, multiply the additive offset b by the segment length (tr - tl + 1), while keeping lazyB[v] as a per-element offset.
Walking the segment tree directly in maxRight(l, pred) finds the threshold index in O(log N) time, shaving a log N factor off binary search + rangeSum.
