Fenwick Trees (Binary Indexed Trees): lowbit Geometry, Point Updates & Range Updates

Demonstrates how two's complement bit isolation i & -i links every 1-based index to its parent responsibility interval.

Intuition first

A Segment Tree over an array of NNN elements requires at least 2N2N2N (or 4N4N4N) nodes because it stores both left and right children at every internal node. Peter Fenwick observed in 1994 that if our operation is an invertible group (like addition), we can discard every right child in a segment tree! If a parent node knows the sum of [1..8][1..8][1..8] and its left child knows [1..4][1..4][1..4], the right child [5..8][5..8][5..8] is redundant because sum(5..8)=sum(1..8)−sum(1..4)\text{sum}(5..8) = \text{sum}(1..8) - \text{sum}(1..4)sum(5..8)=sum(1..8)−sum(1..4). Deleting every right child leaves exactly NNN nodes that map 1-to-1 onto a 1-based array T[1..N]T[1..N]T[1..N].

In this 1-based array, the length of the interval that cell T[i]T[i]T[i] is responsible for equals the value of the lowest set bit of iii: lowbit(i)=i&(−i)\text{lowbit}(i) = i \mathrel{\&} (-i)lowbit(i)=i&(−i) in two's complement arithmetic. Stripping the lowest set bit (i←i−(i&−i)i \leftarrow i - (i \mathrel{\&} -i)i←i−(i&−i)) walks down prefix blocks to accumulate prefixSum(i)\text{prefixSum}(i)prefixSum(i) in at most popcount(i)≤⌈log⁡2N⌉\text{popcount}(i) \le \lceil \log_2 N \rceilpopcount(i)≤⌈log2​N⌉ steps; adding the lowest set bit (i←i+(i&−i)i \leftarrow i + (i \mathrel{\&} -i)i←i+(i&−i)) climbs upward through all enclosing ancestor intervals to apply a point update.

2. O(N)O(N)O(N) Linear-Time Construction & O(log⁡N)O(\log N)O(logN) Binary Lifting (lowerBound)

3. Range Add & Range Sum Using Two Dual Fenwick Trees

Let D[i]=A[i]−A[i−1]D[i] = A[i] - A[i-1]D[i]=A[i]−A[i−1] be the difference array of AAA, so adding +Δ+\Delta+Δ to A[l…r]A[l \dots r]A[l…r] only requires two point updates: D[l]+=ΔD[l] \mathrel{+}= \DeltaD[l]+=Δ and D[r+1]−=ΔD[r+1] \mathrel{-}= \DeltaD[r+1]−=Δ. class FenwickTree {
  /**
   * O(N) linear-time construction from 0-indexed input array
   */
  constructor(arrOrSize) {
    if (typeof arrOrSize === "number") {
      this.n = arrOrSize;
      this.tree = new Float64Array(this.n + 1);
    } else {
      this.n = arrOrSize.length;
      this.tree = new Float64Array(this.n + 1);
      for (let i = 1; i <= this.n; i++) {
        this.tree[i] += arrOrSize[i - 1];
        const parent = i + (i & -i);
        if (parent <= this.n) this.tree[parent] += this.tree[i];
      }
    }
  }

  // Point update: A[idx] += delta (1-indexed: 1 <= idx <= n)
  add(idx, delta) {
    for (let i = idx; i <= this.n; i += i & -i) {
      this.tree[i] += delta;
    }
  }

  // Prefix sum: A[1] + ... + A[idx]
  prefixSum(idx) {
    let sum = 0;
    for (let i = idx; i > 0; i -= i & -i) {
      sum += this.tree[i];
    }
    return sum;
  }

  rangeSum(l, r) {
    return this.prefixSum(r) - this.prefixSum(l - 1);
  }

  /**
   * O(log N) Binary Lifting on Fenwick Tree (requires A[i] >= 0):
   * Returns smallest 1-based index idx such that prefixSum(idx) >= targetSum
   */
  lowerBound(targetSum) {
    let idx = 0;
    let bitMask = 1 << (31 - Math.clz32(this.n));
    for (; bitMask > 0; bitMask >>= 1) {
      const next = idx + bitMask;
      if (next <= this.n && this.tree[next] < targetSum) {
        idx = next;
        targetSum -= this.tree[next];
      }
    }
    return idx + 1;
  }
}

/**
 * Dual Fenwick Tree supporting both Range Add and Range Sum in O(log N)
 */
class RangeFenwickTree {
  constructor(n) {
    this.n = n;
    this.b1 = new FenwickTree(n); // stores D[i]
    this.b2 = new FenwickTree(n); // stores i * D[i]
  }

  rangeAdd(l, r, delta) {
    this.b1.add(l, delta);
    this.b1.add(r + 1, -delta);
    this.b2.add(l, delta * l);
    this.b2.add(r + 1, -delta * (r + 1));
  }

  prefixSum(x) {
    return (x + 1) * this.b1.prefixSum(x) - this.b2.prefixSum(x);
  }

  rangeSum(l, r) {
    return this.prefixSum(r) - this.prefixSum(l - 1);
  }
}

// O(N) Build Fenwick Tree + O(log N) Binary Lifting + Dual Range-Add/Range-Sum BIT (C++20)
class FenwickTree {
    int n;
    std::vector<int64_t> tree;
public:
    explicit FenwickTree(int size) : n(size), tree(size + 1, 0) {}

    explicit FenwickTree(const std::vector<int64_t>& arr)
        : n(static_cast<int>(arr.size())), tree(n + 1, 0) {
        for (int i = 1; i <= n; ++i) {
            tree[i] += arr[i - 1];
            int parent = i + (i & -i);
            if (parent <= n) tree[parent] += tree[i];
        }
    }

    void add(int idx, int64_t delta) noexcept {
        for (int i = idx; i <= n; i += i & -i) tree[i] += delta;
    }

    int64_t prefix_sum(int idx) const noexcept {
        int64_t sum = 0;
        for (int i = idx; i > 0; i -= i & -i) sum += tree[i];
        return sum;
    }

    int64_t range_sum(int l, int r) const noexcept {
        return prefix_sum(r) - prefix_sum(l - 1);
    }

    // Smallest 1-based index idx such that prefix_sum(idx) >= target_sum
    int lower_bound(int64_t target_sum) const noexcept {
        int idx = 0;
        int bit_mask = 1 << (std::bit_width(static_cast<uint32_t>(n)) - 1);
        for (; bit_mask > 0; bit_mask >>= 1) {
            int next = idx + bit_mask;
            if (next <= n && tree[next] < target_sum) {
                idx = next;
                target_sum -= tree[next];
            }
        }
        return idx + 1;
    }
};

Key Takeaways

A Fenwick tree is a segment tree with all right children removed, storing the aggregate of [i - lowbit(i) + 1 .. i] at 1-based index T[i] where lowbit(i) = i & -i.
Passing each node's value to its immediate parent i + (i & -i) constructs a Fenwick tree in exact O(N) time.
Binary lifting on T[] finds the first prefix sum >= K in O(log N) time because T[idx + 2^p] holds the exact sum of the next 2^p elements.
Maintaining two Fenwick trees over D[i] and i * D[i] supports both range additions and range sum queries in O(log N) time.
