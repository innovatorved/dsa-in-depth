Eulerian Trails & Circuits: Degree Conditions & Hierholzer's O(E) Algorithm

5 min read Module 5.1: Graph Representations, Traversals, Connectivity & Topological Order Updated Oct 23, 2026
📄 Cheat Sheet
William Fiset Eulerian Path and Circuit Algorithm (Hierholzer's Algorithm) Watch on YouTube ↗

Demonstrates degree parity conditions and how Hierholzer's post-order splicing avoids O(E^2) dead-end backtracking.

Intuition first

Whereas the Hamiltonian Cycle problem (visiting every vertex exactly once) is NP-complete, the Eulerian Circuit problem—traversing every edge of a graph exactly once—was solved by Leonhard Euler in 1736 (the Seven Bridges of Königsberg) and admits a deterministic O(V+E)O(V + E)O(V+E) algorithm.

Because every time a walk enters and exits an intermediate vertex it consumes two incident edges (or one incoming and one outgoing edge in a directed graph), local degree parity completely determines global existence. Hierholzer's Algorithm (1873) constructs the trail in O(E)O(E)O(E) time by greedily walking until stuck and splicing side-cycles in post-order.

Necessary & Sufficient Degree Conditions

Assume all vertices with non-zero degree belong to a single connected component (or in the directed case, a single weakly connected component whose underlying active vertices satisfy the degree conditions below).

Formal Theorem — Euler-Hierholzer Existence Conditions
  • Undirected Eulerian Circuit (Closed Tour): Exists iff every vertex has even degree (∀u,deg(u)≡0(mod2)\forall u, \text{deg}(u) \equiv 0 \pmod 2∀u,deg(u)≡0(mod2)).
  • Undirected Eulerian Trail (Open Path): Exists iff 000 or 222 vertices have odd degree. If 222 vertices have odd degree, one must be the start vertex and the other the end vertex.
  • Directed Eulerian Circuit: Exists iff every vertex belongs to the same strongly connected component and satisfies in-deg(u)==out-deg(u)\text{in-deg}(u) == \text{out-deg}(u)in-deg(u)==out-deg(u).
  • Directed Eulerian Trail: Exists iff at most one vertex has out-deg(s)−in-deg(s)=1\text{out-deg}(s) - \text{in-deg}(s) = 1out-deg(s)−in-deg(s)=1 (start sss), at most one vertex has in-deg(t)−out-deg(t)=1\text{in-deg}(t) - \text{out-deg}(t) = 1in-deg(t)−out-deg(t)=1 (end ttt), and all other vertices have in-deg(u)==out-deg(u)\text{in-deg}(u) == \text{out-deg}(u)in-deg(u)==out-deg(u).

How Hierholzer's Algorithm Splices Sub-Cycles in O(E)O(E)O(E)

Suppose we start at sss and greedily follow unused outgoing edges, deleting each edge as we traverse it. By the degree invariant, whenever we enter any vertex v≠tv \neq tv=t, there is at least one unused outgoing edge leaving vvv. Thus the greedy walk can only get stuck at the destination vertex ttt (or sss for a circuit)!

However, this initial walk WWW might bypass some edges if the graph contains side-cycles. Instead of splicing linked lists mid-walk, Hierholzer's post-order formulation maintains a per-vertex edge cursor head[u] (just like Dinic's current-arc pointer):

  1. While vertex uuu still has unused outgoing edges, grab the next edge e=(u,v)e = (u, v)e=(u,v), advance head[u]++, and recurse (or push to an explicit stack) on vvv.
  2. Only when uuu has zero remaining outgoing edges do we append uuu to the output vector trail.
  3. Finally, reverse trail. If trail.size() == E + 1, the graph is connected on its edge set and trail is the exact Eulerian path; otherwise the edges belong to disconnected components!

Hardware Reality — Current-Arc Cursor vs. std::set Edge Deletion

Deleting traversed edges from a std::set<int> or std::vector::erase degrades Hierholzer's algorithm to O(Elog⁡V)O(E \log V)O(ElogV) or O(E2)O(E^2)O(E2). Instead, maintain an index cursor idx[u] into each vertex's adjacency vector (advancing idx[u]++) and for undirected graphs mark a flat boolean array usedEdge[edgeId] = 1. This runs in strict O(V+E)O(V + E)O(V+E) with sequential array scans.

Production Implementation: Iterative Hierholzer's Algorithm (Directed & Undirected)

#include <vector>
#include <algorithm>

// Finds a Directed Eulerian Trail/Circuit in O(V + E). Returns empty vector if none exists.
std::vector<int> findDirectedEulerianTrail(int n, int m, const std::vector<std::vector<int>>& adj) {
    std::vector<int> in(n, 0), out(n, 0);
    for (int u = 0; u < n; ++u) {
        out[u] = static_cast<int>(adj[u].size());
        for (int v : adj[u]) ++in[v];
    }

    int start = -1, plusOne = 0, minusOne = 0;
    for (int u = 0; u < n; ++u) {
        int diff = out[u] - in[u];
        if (diff == 1) { ++plusOne; start = u; }
        else if (diff == -1) { ++minusOne; }
        else if (diff != 0) return {};
    }
    if (!((plusOne == 0 && minusOne == 0) || (plusOne == 1 && minusOne == 1))) return {};

    if (start == -1) {
        start = 0;
        for (int u = 0; u < n; ++u) {
            if (out[u] > 0) { start = u; break; }
        }
    }

    std::vector<size_t> cursor(n, 0);
    std::vector<int> st = {start}, trail;
    trail.reserve(m + 1);

    while (!st.empty()) {
        int u = st.back();
        if (cursor[u] < adj[u].size()) {
            int v = adj[u][cursor[u]++];
            st.push_back(v);
        } else {
            trail.push_back(u);
            st.pop_back();
        }
    }

    if (static_cast<int>(trail.size()) != m + 1) return {}; // Disconnected edge components
    std::reverse(trail.begin(), trail.end());
    return trail;
}
Failure Mode — Passing Degree Checks on Disconnected Edge Components

Always check trail.size() == E + 1 after Hierholzer's loop finishes to verify that all EEE edges belong to the same connected component.

In Hierholzer's O(E)O(E)O(E) algorithm, why is a vertex uuu appended to the output trail only when all of its outgoing edges have been exhausted (post-order), rather than when uuu is first visited (pre-order)?

When the greedy walk gets stuck at the end of the trail and unwinds the stack, any vertex u on the stack that still has unused incident edges explores its detour cycle first; emitting in post-order and reversing seamlessly splices all detour cycles in O(1) per edge.

Key Takeaways

An undirected graph has an Eulerian circuit iff every vertex has even degree (and all edges lie in one connected component), and an Eulerian trail iff 0 or 2 vertices have odd degree.
A directed graph has an Eulerian trail iff at most one vertex has out - in = 1, at most one has in - out = 1, and all others have in == out.
Hierholzer's algorithm runs in O(V + E) time by advancing a per-vertex adjacency cursor and emitting vertices in post-order when their outgoing edges are exhausted.
Always verify that the resulting vertex sequence has length exactly E + 1 to guard against disconnected cycles passing the local degree test.
