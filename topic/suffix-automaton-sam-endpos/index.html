Suffix Automaton (SAM / DAWG): endpos Equivalence Classes & State Transitions

7 min read Module 4.2: Suffix Structures, Sequence Alignment & Data Compression Updated Oct 23, 2026
📄 Cheat Sheet
Sebastian Wild (Lectures) LCP Array Construction (Kasai's O(N) Algorithm) & Suffix Array Duality Watch on YouTube ↗

Derives the endpos equivalence relation, suffix link tree, state cloning rule when len[q] > len[p] + 1, and proves the 2N - 1 state bound and 3N - 4 transition bound.

Intuition first

A Suffix Automaton (SAM, or Directed Acyclic Word Graph / DAWG, Blumer et al. 1985) is the smallest deterministic finite automaton that recognizes all substrings of a string $S[0..N-1]$. How can a DFA that accepts up to $\Theta(N^2)$ distinct substrings have at most $2N - 1$ states and $3N - 4$ transitions? By grouping substrings that always finish at the exact same set of text positions into a single state!

Formally, for any non-empty substring $t$ of $S$, let $\text{endpos}(t) \subseteq \{0, 1, \dots, N-1\}$ be the set of 0-based indices in $S$ where occurrences of $t$ end. Two substrings $u$ and $v$ are $\text{endpos}$-equivalent ($u \sim v$) if and only if $\text{endpos}(u) = \text{endpos}(v)$. Every state $q$ in the Suffix Automaton corresponds bijectively to one $\text{endpos}$ equivalence class, representing a contiguous interval of suffix lengths $[\text{minlen}(q),\; \text{len}(q)]$, where $\text{minlen}(q) = \text{len}(\text{link}(q)) + 1$!

1. The Four Fundamental Lemmas of $\text{endpos}(t)$

Every property of the Suffix Automaton follows from four elementary facts about $\text{endpos}(t)$:

  1. Nested Suffix Inclusion: If $|u| \le |w|$ and $\text{endpos}(u) \cap \text{endpos}(w) \neq \emptyset$, then $u$ MUST be a suffix of $w$, which implies $\text{endpos}(w) \subseteq \text{endpos}(u)$. Thus any two $\text{endpos}$ sets are either completely disjoint or one is a subset of the other!
  2. Contiguous Suffix Interval per State: All substrings inside a single equivalence class $q$ are suffixes of the longest substring $W(q)$ in $q$ (of length $\text{len}[q]$), and they consist of all suffixes of $W(q)$ of lengths in the contiguous range $[\text{minlen}[q],\; \text{len}[q]]$.
  3. The Suffix Link Tree ($\text{link}[q]$): As you shorten $W(q)$ one character at a time from the left, the set of ending positions stays equal to $\text{endpos}(q)$ down to length $\text{minlen}[q]$, and at length $\text{minlen}[q] - 1$ it strictly expands into a larger $\text{endpos}$ set! That state is defined as $\text{link}[q]$, so: $$\text{minlen}[q] = \text{len}[\text{link}[q]] + 1$$ Because $\text{endpos}$ sets are either disjoint or nested, the links $\text{link}[q]$ form a rooted tree (the Link Tree) with at most $N$ leaves, proving the automaton has at most $2N - 1$ states (and at most $3N - 4$ edges).
  4. Instant Substring Count: Since state $q$ represents exactly $\text{len}[q] - \text{len}[\text{link}[q]]$ distinct substrings and states partition all non-empty substrings of $S$, the total number of distinct substrings of $S$ is simply $\sum_{q > 0} (\text{len}[q] - \text{len}[\text{link}[q]])$.

2. Online $O(N)$ Extension & State Cloning

When we append character $c = S[i]$ to the string processed so far (whose full prefix state is $\text{last}$), we create a new state $\text{cur}$ with $\text{len}[\text{cur}] = \text{len}[\text{last}] + 1$, walk up the suffix link chain $p = \text{last}, \text{link}[\text{last}], \dots$ adding transition $\text{next}[p][c] = \text{cur}$ while $\text{next}[p][c]$ is absent, and then handle three cases:

  • Case 1 (Reached root with no existing $c$-edge): Set $\text{link}[\text{cur}] = 0$ (the root).
  • Case 2 ($q = \text{next}[p][c]$ exists and $\text{len}[q] == \text{len}[p] + 1$): State $q$ contains ONLY suffixes of the new string, so we simply set $\text{link}[\text{cur}] = q$.
  • Case 3 ($q = \text{next}[p][c]$ exists and $\text{len}[q] > \text{len}[p] + 1$): State $q$ contains strings longer than $\text{len}[p] + 1$ that do NOT end at index $i$, so their $\text{endpos}$ set has split from the shorter suffixes of length $\le \text{len}[p] + 1$! We clone $q$ into a new state $\text{clone}$ with $\text{len}[\text{clone}] = \text{len}[p] + 1$, copy $q$'s outgoing transitions and suffix link to $\text{clone}$, redirect transitions $\text{next}[p][c] == q$ along $p$'s link chain to $\text{clone}$, and set $\text{link}[q] = \text{link}[\text{cur}] = \text{clone}$.
SAM Metric / Operation Worst-Case Bound Key Structural Reason
Number of States $|V|$ $\le 2N - 1$ (for $N \ge 2$) Each extend adds $1$ primary state + at most $1$ clone; tree of disjoint $\text{endpos}$ sets
Number of Transitions $|E|$ $\le 3N - 4$ (for $N \ge 3$) Spanning tree of longest paths ($|V| - 1$) + at most $N + 1$ non-tree shortcuts
Distinct Substrings of $S$ $O(N)$ $\sum_{u > 0} (\text{len}[u] - \text{len}[\text{link}[u]])$
Longest Common Substring of $S$ and $T$ $O(|S| + |T|)$ Feed $T$ through SAM of $S$, falling back via $\text{link}[u]$ on mismatch
SAM Partition & Clone-Occurrence Invariant

Every non-empty substring of $S$ belongs to a unique state $u$ of the SAM, and $|\text{endpos}(u)|$ equals the number of non-cloned primary states in the subtree of $u$ in the Suffix Link Tree. When a state $q$ is cloned into $\text{clone}$, the primary state receives initial count $\text{cnt}[\text{cur}] = 1$ while $\text{cnt}[\text{clone}] = 0$ so that bottom-up link-tree aggregation never double-counts occurrences.

Preallocating 2N States & Length-Bucket Topological Sort

Because $|V| \le 2N$, calling st.reserve(2 * n) up front avoids all vector reallocations during construction. Furthermore, to aggregate occurrence counts bottom-up on the Link Tree ($ ext{cnt}[ ext{link}[u]] mathrel{+}= ext{cnt}[u]$), you do NOT need to build adjacency lists or run recursion: simply counting-sort states by $ ext{len}[u]$ in $O(N)$ time and iterate from longest $ ext{len}[u]$ down to $1$!

4. Production Implementation: Suffix Automaton + LCS of Two Strings

#include <algorithm>
#include <array>
#include <cstdint>
#include <string_view>
#include <vector>

class SuffixAutomaton {
public:
    struct State {
        std::array<int, 26> next;
        int len = 0;
        int link = -1;
        State() { next.fill(-1); }
    };

    explicit SuffixAutomaton(std::string_view s) {
        st_.reserve(2 * s.size() + 1);
        st_.emplace_back(); // State 0 = root
        for (char ch : s) extend(ch - 'a');
    }

    void extend(int c) {
        int cur = static_cast<int>(st_.size());
        st_.emplace_back();
        st_[cur].len = st_[last_].len + 1;

        int p = last_;
        while (p != -1 && st_[p].next[c] == -1) {
            st_[p].next[c] = cur;
            p = st_[p].link;
        }
        if (p == -1) {
            st_[cur].link = 0;
        } else {
            int q = st_[p].next[c];
            if (st_[p].len + 1 == st_[q].len) {
                st_[cur].link = q;
            } else {
                int clone = static_cast<int>(st_.size());
                st_.push_back(st_[q]); // Copies next[] and link
                st_[clone].len = st_[p].len + 1;
                while (p != -1 && st_[p].next[c] == q) {
                    st_[p].next[c] = clone;
                    p = st_[p].link;
                }
                st_[q].link = st_[cur].link = clone;
            }
        }
        last_ = cur;
    }

    int64_t count_distinct_substrings() const {
        int64_t total = 0;
        for (size_t u = 1; u < st_.size(); ++u) {
            total += st_[u].len - st_[st_[u].link].len;
        }
        return total;
    }

    // Returns length of Longest Common Substring with T in O(|T|) time
    int longest_common_substring(std::string_view t) const {
        int u = 0, cur_len = 0, best = 0;
        for (char ch : t) {
            int c = ch - 'a';
            while (u != 0 && st_[u].next[c] == -1) {
                u = st_[u].link;
                cur_len = st_[u].len;
            }
            if (st_[u].next[c] != -1) {
                u = st_[u].next[c];
                ++cur_len;
            }
            best = std::max(best, cur_len);
        }
        return best;
    }

private:
    std::vector<State> st_;
    int last_ = 0;
};
Resetting Matched Length cur_len = st_[u].len on SAM Fallback

When matching a query string $T$ against a Suffix Automaton to find the Longest Common Substring, if state $u$ lacks transition $c$ and you follow $u \leftarrow \text{link}[u]$, your matched length cur_len MUST be reset to $\text{len}[u]$ (the maximum length in the new state)! A frequent bug is decrementing cur_len-- by $1$ on each suffix-link hop; because a single suffix-link hop can drop $\text{len}[u]$ by many characters at once, cur_len-- grossly overestimates the match length.

Concept Check Structure of Substrings Within a Single SAM State recall

Each state $u > 0$ in a Suffix Automaton (SAM) corresponds to an equivalence class of non-empty substrings of $S$ that have the exact same set of ending positions $\text{endpos}(u)$.

If two substrings $x$ and $y$ ($|x| \le |y|$) share the same $\text{endpos}$ set, $x$ must be a suffix of $y$, and every suffix $z$ of $y$ with $|x| \le |z| \le |y|$ satisfies $\text{endpos}(y) \subseteq \text{endpos}(z) \subseteq \text{endpos}(x) = \text{endpos}(y)$. The suffix link $\text{link}[u]$ points to the longest suffix of $W(u)$ whose $\text{endpos}$ set is strictly larger, so state $u$ holds all lengths in $[\text{len}[\text{link}[u]] + 1,\; \text{len}[u]]$.
Concept Check Why State Cloning Happens When $\text{len}[q] > \text{len}[p] + 1$ apply

During `extend(c)` at index $i$, we walk up the suffix link chain from `last` and stop at the first state $p$ that already has a transition $q = \text{next}[p][c]$. Suppose $\text{len}[q] > \text{len}[p] + 1$.

Before index $i$, all strings in $q$ of lengths $[\text{minlen}[q], \text{len}[q]]$ shared the same $\text{endpos}$ set. At index $i$, the suffix of length $\text{len}[p] + 1$ (and shorter suffixes in $q$) just occurred again at position $i$, whereas strings in $q$ of length $> \text{len}[p] + 1$ did NOT occur at position $i$. Cloning $q$ separates $q$ into `clone` (lengths $\le \text{len}[p] + 1$, which gain $i$ in $\text{endpos}$) and $q$ (lengths $> \text{len}[p] + 1$, whose $\text{endpos}$ is unchanged).
Concept Check Computing $|\text{endpos}(u)|$ (Substring Occurrence Frequency) on a SAM apply

You want to answer queries of the form: given pattern $P$, how many times does $P$ appear in $S$? After walking $P$ from the root of the SAM to state $u$, the answer is $|\text{endpos}(u)|$.

Each prefix $S[0..i]$ ends at a unique primary state `cur_i`, corresponding to the ending position $i \in \{0, \dots, N-1\}$. A substring in state $u$ ends at position $i$ if and only if $u$ is an ancestor of `cur_i` in the Suffix Link Tree! Giving primary states weight $1$ and cloned states weight $0$ ensures that summing weights bottom-up on the Link Tree counts the exact number of ending positions in $\text{endpos}(u)$.
Concept Check Exact Worst-Case State and Transition Bounds of a Suffix Automaton staff

For any string $S$ of length $N \ge 3$, what are the tightest worst-case upper bounds on the number of states $|V|$ and directed transitions $|E|$ in its Suffix Automaton, and what string families achieve them?

The first two characters create at most 3 states without clones, and each of the remaining $N - 2$ characters creates 1 primary state and at most 1 clone: $3 + 2(N - 2) = 2N - 1$ states (achieved on $\texttt{"ab"}^{N-1}$ or $\texttt{"abbb...b"}$). For transitions, a spanning tree of longest paths from the root uses $|V| - 1 \le 2N - 2$ edges, and each suffix $S[i..N-1]$ contributes at most 1 non-tree shortcut edge along the path before merging, yielding $|E| \le (2N - 2) + (N - 2) = 3N - 4$ (achieved on $\texttt{"ab"}^{N-2}\texttt{"c"}$).

Key Takeaways

A Suffix Automaton (SAM) groups substrings with identical endpos sets into a single state covering suffix lengths [len[link[u]] + 1, len[u]], using at most 2N - 1 states and 3N - 4 transitions.
Whenever extending along p -> q encounters len[q] > len[p] + 1, state q must be cloned into a state of length len[p] + 1 because longer strings in q do not share the new end position.
The total number of distinct substrings in S is simply sum_{u > 0} (len[u] - len[link[u]]), and the Longest Common Substring with T is found in O(|S| + |T|) time.
