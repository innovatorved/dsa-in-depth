Derives the endpos equivalence relation, suffix link tree, state cloning rule when len[q] > len[p] + 1, and proves the 2N - 1 state bound and 3N - 4 transition bound.

Intuition first

A Suffix Automaton (SAM, or Directed Acyclic Word Graph / DAWG, Blumer et al. 1985) is the smallest deterministic finite automaton that recognizes all substrings of a string S[0..N−1]S[0..N-1]S[0..N−1]. How can a DFA that accepts up to Θ(N2)\Theta(N^2)Θ(N2) distinct substrings have at most 2N−12N - 12N−1 states and 3N−43N - 43N−4 transitions? By grouping substrings that always finish at the exact same set of text positions into a single state!

Formally, for any non-empty substring ttt of SSS, let endpos(t)⊆{0,1,…,N−1}\text{endpos}(t) \subseteq \{0, 1, \dots, N-1\}endpos(t)⊆{0,1,…,N−1} be the set of 0-based indices in SSS where occurrences of ttt end. Two substrings uuu and vvv are endpos\text{endpos}endpos-equivalent (u∼vu \sim vu∼v) if and only if endpos(u)=endpos(v)\text{endpos}(u) = \text{endpos}(v)endpos(u)=endpos(v). Every state qqq in the Suffix Automaton corresponds bijectively to one endpos\text{endpos}endpos equivalence class, representing a contiguous interval of suffix lengths [minlen(q),  len(q)][\text{minlen}(q),\; \text{len}(q)][minlen(q),len(q)], where minlen(q)=len(link(q))+1\text{minlen}(q) = \text{len}(\text{link}(q)) + 1minlen(q)=len(link(q))+1!

1. The Four Fundamental Lemmas of endpos(t)\text{endpos}(t)endpos(t)

Every property of the Suffix Automaton follows from four elementary facts about endpos(t)\text{endpos}(t)endpos(t):

  1. Nested Suffix Inclusion: If ∣u∣≤∣w∣|u| \le |w|∣u∣≤∣w∣ and endpos(u)∩endpos(w)≠∅\text{endpos}(u) \cap \text{endpos}(w) \neq \emptysetendpos(u)∩endpos(w)=∅, then uuu MUST be a suffix of www, which implies endpos(w)⊆endpos(u)\text{endpos}(w) \subseteq \text{endpos}(u)endpos(w)⊆endpos(u). Thus any two endpos\text{endpos}endpos sets are either completely disjoint or one is a subset of the other!
  2. Contiguous Suffix Interval per State: All substrings inside a single equivalence class qqq are suffixes of the longest substring W(q)W(q)W(q) in qqq (of length len[q]\text{len}[q]len[q]), and they consist of all suffixes of W(q)W(q)W(q) of lengths in the contiguous range [minlen[q],  len[q]][\text{minlen}[q],\; \text{len}[q]][minlen[q],len[q]].
  3. The Suffix Link Tree (link[q]\text{link}[q]link[q]): As you shorten W(q)W(q)W(q) one character at a time from the left, the set of ending positions stays equal to endpos(q)\text{endpos}(q)endpos(q) down to length minlen[q]\text{minlen}[q]minlen[q], and at length minlen[q]−1\text{minlen}[q] - 1minlen[q]−1 it strictly expands into a larger endpos\text{endpos}endpos set! That state is defined as link[q]\text{link}[q]link[q], so: minlen[q]=len[link[q]]+1\text{minlen}[q] = \text{len}[\text{link}[q]] + 1minlen[q]=len[link[q]]+1 Because endpos\text{endpos}endpos sets are either disjoint or nested, the links link[q]\text{link}[q]link[q] form a rooted tree (the Link Tree) with at most NNN leaves, proving the automaton has at most 2N−12N - 12N−1 states (and at most 3N−43N - 43N−4 edges).

#include <algorithm>
#include <array>
#include <cstdint>
#include <string_view>
#include <vector>

class SuffixAutomaton {
public:
    struct State {
        std::array<int, 26> next;
        int len = 0;
        int link = -1;
        State() { next.fill(-1); }
    };

    explicit SuffixAutomaton(std::string_view s) {
        st_.reserve(2 * s.size() + 1);
        st_.emplace_back(); // State 0 = root
        for (char ch : s) extend(ch - 'a');
    }

    void extend(int c) {
        int cur = static_cast<int>(st_.size());
        st_.emplace_back();
        st_[cur].len = st_[last_].len + 1;

        int p = last_;
        while (p != -1 && st_[p].next[c] == -1) {
            st_[p].next[c] = cur;
            p = st_[p].link;
        }
        if (p == -1) {
            st_[cur].link = 0;
        } else {
            int q = st_[p].next[c];
            if (st_[p].len + 1 == st_[q].len) {
                st_[cur].link = q;
            } else {
                int clone = static_cast<int>(st_.size());
                st_.push_back(st_[q]); // Copies next[] and link
                st_[clone].len = st_[p].len + 1;
                while (p != -1 && st_[p].next[c] == q) {
                    st_[p].next[c] = clone;
                    p = st_[p].link;
                }
                st_[q].link = st_[cur].link = clone;
            }
        }
        last_ = cur;
    }

    int64_t count_distinct_substrings() const {
        int64_t total = 0;
        for (size_t u = 1; u < st_.size(); ++u) {
            total += st_[u].len - st_[st_[u].link].len;
        }
        return total;
    }

    // Returns length of Longest Common Substring with T in O(|T|) time
    int longest_common_substring(std::string_view t) const {
        int u = 0, cur_len = 0, best = 0;
        for (char ch : t) {
            int c = ch - 'a';
            while (u != 0 && st_[u].next[c] == -1) {
                u = st_[u].link;
                cur_len = st_[u].len;
            }
            if (st_[u].next[c] != -1) {
                u = st_[u].next[c];
                ++cur_len;
            }
            best = std::max(best, cur_len);
        }
        return best;
    }

private:
    std::vector<State> st_;
    int last_ = 0;
};

Key Takeaways

A Suffix Automaton (SAM) groups substrings with identical endpos sets into a single state covering suffix lengths [len[link[u]] + 1, len[u]], using at most 2N - 1 states and 3N - 4 transitions.
Whenever extending along p -> q encounters len[q] > len[p] + 1, state q must be cloned into a state of length len[p] + 1 because longer strings in q do not share the new end position.
The total number of distinct substrings in S is simply sum_{u > 0} (len[u] - len[link[u]]), and the Longest Common Substring with T is found in O(|S| + |T|) time.
