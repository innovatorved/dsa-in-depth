Palindromes in O(N): Manacher's Algorithm & Eertree (Palindromic Automaton)

6 min read Module 4.1: Tries, Exact String Matching & Multi-Pattern Automata Updated Oct 22, 2026
📄 Cheat Sheet
Tushar Roy - Coding Made Simple Manacher's Algorithm - Longest Palindromic Substring in O(N) Watch on YouTube ↗

Walks through center reflection across the rightmost palindrome boundary [L, R] and proves why the outer boundary R advances at most 2N times.

Intuition first

Expanding around every possible palindrome center in a string of length NNN takes O(N2)O(N^2)O(N2) time on inputs like "aaaa...a"\texttt{"aaaa...a"}"aaaa...a" because each center re-discovers symmetry that was already proved by an enclosing palindrome. Glenn Manacher (1975) noticed that if you maintain the palindrome [L,R][L, R][L,R] with the rightmost right boundary RRR seen so far, any new center i<Ri < Ri<R has a mirror center i′=L+(R−i)i' = L + (R - i)i′=L+(R−i) across the midpoint of [L,R][L, R][L,R]. Exactly like the Z-algorithm's [L,R][L, R][L,R] Z-box, you can copy P[i′]P[i']P[i′] as a free lower bound for P[i]P[i]P[i] and only perform character comparisons when the palindrome around iii pushes strictly past RRR.

When a problem asks not just for the longest palindrome at each center, but for the distinct palindromic substrings, their occurrence frequencies, or palindromic factorizations, Mikhail Rubinchik and Arseny Shur's Eertree (Palindromic Tree / Palindromic Automaton, 2015) provides the exact structural dual of a Trie: a graph with two roots (lengths −1-1−1 and 000) where every edge u→cc S(u) cu \xrightarrow{c} c\,S(u)\,cuc​cS(u)c wraps a character symmetrically around both ends of a palindrome, proving constructively that a string of length NNN contains at most NNN distinct non-empty palindromic substrings.

1. Manacher's Algorithm: Odd/Even Unification & Mirror Reflection

Palindromes come in two parities: odd-length (centered on a character, like "aba"\texttt{"aba"}"aba") and even-length (centered between two characters, like "abba"\texttt{"abba"}"abba"). To avoid writing two separate passes, we transform S[0..N−1]S[0..N-1]S[0..N−1] into T[0..2N]T[0..2N]T[0..2N] of length 2N+12N + 12N+1 by interleaving a separator ’#’\texttt{'\#'}’#’: for S="abba"S = \texttt{"abba"}S="abba", T="#a#b#b#a#"T = \texttt{"\#a\#b\#b\#a\#"}T="#a#b#b#a#". Every odd or even palindrome in SSS now maps bijectively to an odd-length palindrome in TTT, and the radius p[i]p[i]p[i] (number of matching characters strictly to one side of T[i]T[i]T[i]) equals the exact length of the corresponding palindrome in SSS!

We maintain the active palindrome interval [L,R]=[c−p[c],  c+p[c]][L, R] = [c - p[c],\; c + p[c]][L,R]=[c−p[c],c+p[c]] with maximum right endpoint RRR. For index iii from 000 to 2N2N2N:

  1. If i<Ri < Ri<R, let i′=L+R−ii' = L + R - ii′=L+R−i be the reflection of iii across center ccc. Because T[L..R]T[L..R]T[L..R] is a palindrome, the neighborhood around iii is the reverse of the neighborhood around i′i'i′ up to the boundary R−iR - iR−i. Thus we initialize: p[i]=min⁡(R−i,  p[i′])p[i] = \min(R - i,\; p[i'])p[i]=min(R−i,p[i′])
  2. We then attempt to expand p[i]p[i]p[i] greedily while T[i−p[i]−1]=T[i+p[i]+1]T[i - p[i] - 1] = T[i + p[i] + 1]T[i−p[i]−1]=T[i+p[i]+1]. Note that if p[i′]<R−ip[i'] < R - ip[i′]<R−i, the palindrome at i′i'i′ stopped strictly inside [L,R][L, R][L,R] due to a mismatch T[i′−p[i′]−1]≠T[i′+p[i′]+1]T[i' - p[i'] - 1] \neq T[i' + p[i'] + 1]T[i′−p[i′]−1]=T[i′+p[i′]+1]; by symmetry, the characters at i±(p[i′]+1)i \pm (p[i'] + 1)i±(p[i′]+1) also mismatch, so the expansion loop terminates on its first check!
  3. Whenever i+p[i]>Ri + p[i] > Ri+p[i]>R, we update (L,R)←(i−p[i],  i+p[i])(L, R) \leftarrow (i - p[i],\; i + p[i])(L,R)←(i−p[i],i+p[i]). Since every successful character comparison increments RRR, and R≤2NR \le 2NR≤2N, Manacher's algorithm performs at most 2N+12N + 12N+1 successful comparisons in total: O(N)O(N)O(N) worst-case time.

2. Eertree (Palindromic Automaton): At Most NNN Distinct Palindromes

How many distinct palindromic substrings can S[0..N−1]S[0..N-1]S[0..N−1] contain? Consider appending c=S[i]c = S[i]c=S[i] to prefix S[0..i−1]S[0..i-1]S[0..i−1]. Suppose two new palindromes PlongP_{\text{long}}Plong​ and PshortP_{\text{short}}Pshort​ both end at index iii (∣Pshort∣<∣Plong∣|P_{\text{short}}| < |P_{\text{long}}|∣Pshort​∣<∣Plong​∣). Because PshortP_{\text{short}}Pshort​ is a suffix of PlongP_{\text{long}}Plong​ and PlongP_{\text{long}}Plong​ is a palindrome, PshortP_{\text{short}}Pshort​ must also appear as a prefix of PlongP_{\text{long}}Plong​—meaning PshortP_{\text{short}}Pshort​ already occurred earlier inside S[0..i−1]S[0..i-1]S[0..i−1]! Thus appending S[i]S[i]S[i] can create at most one new distinct palindrome (the longest palindromic suffix of S[0..i]S[0..i]S[0..i]), so a string of length NNN has ≤N\le N≤N distinct non-empty palindromes.

An Eertree stores each distinct palindrome as a node uuu with length len[u]\text{len}[u]len[u], transition next[u][c]\text{next}[u][c]next[u][c] representing the palindrome c+S(u)+cc + S(u) + cc+S(u)+c of length len[u]+2\text{len}[u] + 2len[u]+2, and suffix link link[u]\text{link}[u]link[u] pointing to the longest proper palindromic suffix of S(u)S(u)S(u):

  • Two Roots: Node 111 is the imaginary odd root with len[1]=−1\text{len}[1] = -1len[1]=−1 (so wrapping ccc around node 111 gives len=−1+2=1\text{len} = -1 + 2 = 1len=−1+2=1, a single character ccc), and Node 222 is the even empty root with len[2]=0\text{len}[2] = 0len[2]=0 and link[2]=1\text{link}[2] = 1link[2]=1 (so wrapping ccc around node 222 gives cccccc of length 222).
  • Online Extension: From the longest palindromic suffix uuu of S[0..i−1]S[0..i-1]S[0..i−1], we follow u←link[u]u \leftarrow \text{link}[u]u←link[u] until S[i−1−len[u]]=S[i]S[i - 1 - \text{len}[u]] = S[i]S[i−1−len[u]]=S[i]. Then next[u][S[i]]\text{next}[u][S[i]]next[u][S[i]] is the longest palindromic suffix of S[0..i]S[0..i]S[0..i].

Sentinel Boundary Padding in Manacher

Adding distinct sentinel characters at both ends of the transformed string—e.g., T = \texttt{"^\#a\#b\#a\#\"}wherewherewhere\texttt{'^'},,,\texttt{'\'}, and ’#’\texttt{'\#'}’#’ do not appear in SSS—eliminates the bounds checks i - p[i] - 1 >= 0 && i + p[i] + 1 < m from the inner expansion loop. The loop condition simplifies to a single character comparison T[i - p[i] - 1] == T[i + p[i] + 1], cutting inner-loop branch instructions in half.

// 1. Manacher's Algorithm with Sentinel Padding: returns p[i] on "^#s0#s1#...#$"
std::vector<int> manacher_radii(std::string_view s) {
    std::string t = "^#";
    t.reserve(2 * s.size() + 4);
    for (char c : s) {
        t.push_back(c);
        t.push_back('#');
    }
    t.push_back('$');

    const int m = static_cast<int>(t.size());
    std::vector<int> p(m, 0);
    int l = 1, r = 1;
    for (int i = 1; i < m - 1; ++i) {
        if (i < r) {
            p[i] = std::min(r - i, p[l + r - i]);
        }
        while (t[i - p[i] - 1] == t[i + p[i] + 1]) {
            ++p[i];
        }
        if (i + p[i] > r) {
            l = i - p[i];
            r = i + p[i];
        }
    }
    return p; // Max value in p equals length of longest palindromic substring of s
}

// 2. Eertree (Palindromic Automaton): counts distinct palindromes & total occurrences
struct Eertree {
    struct Node {
        std::array<int, 26> next{};
        int len = 0;
        int link = 0;
        long long occ = 0; // Occurrence count (accumulated bottom-up)
    };
    std::vector<Node> nodes;
    std::string s;
    int last = 2;

    Eertree() {
        nodes.resize(3);
        nodes[1].len = -1; nodes[1].link = 1; // Odd root
        nodes[2].len = 0;  nodes[2].link = 1; // Even root
    }

    int get_fail(int u, int pos) const {
        while (pos - 1 - nodes[u].len < 0 || s[pos - 1 - nodes[u].len] != s[pos]) {
            u = nodes[u].link;
        }
        return u;
    }

    void add_char(char ch) {
        int pos = static_cast<int>(s.size());
        s.push_back(ch);
        int c = ch - 'a';
        int cur = get_fail(last, pos);
        if (nodes[cur].next[c] == 0) {
            int now = static_cast<int>(nodes.size());
            nodes.emplace_back();
            nodes[now].len = nodes[cur].len + 2;
            if (nodes[now].len == 1) {
                nodes[now].link = 2; // Single char links to Even Root (len 0)
            } else {
                nodes[now].link = nodes[get_fail(nodes[cur].link, pos)].next[c];
            }
            nodes[cur].next[c] = now;
        }
        last = nodes[cur].next[c];
        nodes[last].occ++;
    }

    // Call after adding all characters to propagate occurrence counts up suffix links
    long long total_palindromic_substrings() {
        long long total = 0;
        for (int i = static_cast<int>(nodes.size()) - 1; i >= 3; --i) {
            nodes[nodes[i].link].occ += nodes[i].occ;
            total += nodes[i].occ;
        }
        return total;
    }
};
Eertree Evaluation Order When Computing Link Before Attaching Child

In Eertree's add_char, you MUST compute nodes[now].link BEFORE setting nodes[cur].next[c] = now (or explicitly handle nodes[now].len == 1 first). When cur == 1 (the odd root of length −1-1−1), nodes[cur].link is also 111; if you assign nodes[1].next[c] = now before computing nodes[now].link, then nodes[get_fail(nodes[1].link, pos)].next[c] will find now itself and create a self-loop nodes[now].link = now instead of linking to the even root 222!

Key Takeaways

Manacher's algorithm interleaves '#' separators so every odd and even palindrome becomes odd-length, and reflects i across the center of the rightmost palindrome [L, R] to run in O(N) time.
Every string of length N contains at most N distinct non-empty palindromic substrings because any shorter palindromic suffix at index i is reflected into an earlier occurrence by the longest palindromic suffix.
An Eertree (Palindromic Automaton) uses two roots (len = -1 and len = 0) and suffix links between palindromes to count distinct palindromes and their exact frequencies in O(N) time.
