Cartesian Trees: Linear-Time Monotonic Stack Construction & RMQ-LCA Duality

5 min read Module 3.3: Range Query & Sublinear Decomposition Structures Updated Oct 21, 2026
📄 Cheat Sheet

Concise derivation of how a Cartesian Tree encodes array indices in-order and values in min-heap order, reducing Range Minimum Queries to Lowest Common Ancestor.

Intuition first

Given an array A[0..N−1]A[0..N-1]A[0..N−1], its Min-Cartesian Tree (introduced by Jean Vuillemin in 1980) is the unique binary tree whose inorder traversal reproduces the array indices 0,1,…,N−10, 1, \dots, N-10,1,…,N−1 and whose nodes satisfy the min-heap property on values A[i]A[i]A[i] (A[parent]≤A[child]A[\text{parent}] \le A[\text{child}]A[parent]≤A[child]). Equivalently, the root of the Cartesian tree for A[L..R]A[L..R]A[L..R] is the index m=arg⁡min⁡i∈[L,R]A[i]m = \arg\min_{i \in [L, R]} A[i]m=argmini∈[L,R]​A[i], its left subtree is the Cartesian tree of A[L..m−1]A[L..m-1]A[L..m−1], and its right subtree is the Cartesian tree of A[m+1..R]A[m+1..R]A[m+1..R].

Two remarkable consequences follow immediately. First, for any range [L,R][L, R][L,R], the Lowest Common Ancestor LCA(L,R)\text{LCA}(L, R)LCA(L,R) in the Cartesian tree is the unique ancestor falling between LLL and RRR in inorder traversal—which is literally arg⁡min⁡i∈[L,R]A[i]\arg\min_{i \in [L, R]} A[i]argmini∈[L,R]​A[i]! Thus any static Range Minimum Query (RMQ) reduces in Θ(N)\Theta(N)Θ(N) time to LCA on a Cartesian tree, and conversely LCA reduces to ±1\pm 1±1 RMQ via Euler Tour (RMQ-LCA Duality). Second, we can construct the Cartesian tree in strict Θ(N)\Theta(N)Θ(N) time by inserting indices i=0,1,…,N−1i = 0, 1, \dots, N-1i=0,1,…,N−1 from left to right while maintaining the tree's right spine on a monotonic increasing stack!

1. Linear-Time Θ(N)\Theta(N)Θ(N) Right-Spine Construction via Monotonic Stack

Suppose we have already built the Cartesian tree for prefix A[0..i−1]A[0..i-1]A[0..i−1]. Because index iii is larger than every index in 0,…,i−1{0, \dots, i-1}0,…,i−1, node iii must be placed somewhere along the rightmost spine of the current tree (and cannot have a right child yet). As we climb up the right spine from the bottommost node, any spine node sss with A[s]>A[i]A[s] > A[i]A[s]>A[i] violates the min-heap invariant if sss remains above iii. Therefore:

  1. Pop all nodes sss from the right-spine stack that have A[s]>A[i]A[s] > A[i]A[s]>A[i]; let lastlastlast be the last node popped (the shallowest popped node with A[last]>A[i]A[last] > A[i]A[last]>A[i]).
  2. Make lastlastlast the left child of iii (left[i] = last), preserving the inorder requirement because all indices in lastlastlast's subtree are <i< i<i.
  3. If the stack is still non-empty, its top node ppp satisfies A[p]≤A[i]A[p] \le A[i]A[p]≤A[i]; attach iii as the right child of ppp (right[p] = i). Push iii onto the right-spine stack.

Because each index i∈[0,N−1]i \in [0, N-1]i∈[0,N−1] is pushed onto the right-spine stack once and popped at most once, the entire construction runs in at most 2N2N2N stack operations—exact Θ(N)\Theta(N)Θ(N) time!

2. Production Implementation: Θ(N)\Theta(N)Θ(N) Cartesian Tree & All-Subarray-Minimums Summation

JAVASCRIPT67 lines
/**
 * Constructs the Min-Cartesian Tree of arr[0..N-1] in exact Theta(N) time
 * using a monotonic right-spine stack.
 * Ties broken by smaller index (arr[stack[top]] > arr[i] pops strictly greater values).
 */
function buildCartesianTree(arr) {
  const n = arr.length;
  const parent = new Int32Array(n).fill(-1);
  const left = new Int32Array(n).fill(-1);
  const right = new Int32Array(n).fill(-1);
  const stack = new Int32Array(n);
  let top = -1;

  for (let i = 0; i < n; i++) {
    let lastPopped = -1;
    // Pop nodes from right spine that are strictly greater than arr[i]
    while (top >= 0 && arr[stack[top]] > arr[i]) {
      lastPopped = stack[top--];
    }
    // The shallowest popped node becomes the left child of i
    if (lastPopped !== -1) {
      left[i] = lastPopped;
      parent[lastPopped] = i;
    }
    // If stack is non-empty, i becomes the right child of stack[top]
    if (top >= 0) {
      right[stack[top]] = i;
      parent[i] = stack[top];
    }
    stack[++top] = i;
  }

  // The root of the entire Cartesian tree is at the bottom of the right spine (stack[0])
  const root = n > 0 ? stack[0] : -1;
  return { root, parent, left, right };
}

/**
 * Application: Sum of min(A[L..R]) over all N*(N+1)/2 subarrays in O(N) time!
 * In the Cartesian tree, node i is the minimum for all subarrays [L, R]
 * where L is in i's left subtree (+ i) and R is in i's right subtree (+ i).
 */
function sumOfSubarrayMinimums(arr) {
  const n = arr.length;
  const { root, left, right } = buildCartesianTree(arr);
  const sz = new Int32Array(n);
  let totalSum = 0;

  // Iterative post-order traversal
  const order = [];
  const stack = root !== -1 ? [root] : [];
  while (stack.length > 0) {
    const u = stack.pop();
    order.push(u);
    if (left[u] !== -1) stack.push(left[u]);
    if (right[u] !== -1) stack.push(right[u]);
  }

  for (let idx = order.length - 1; idx >= 0; idx--) {
    const u = order[idx];
    const szL = left[u] !== -1 ? sz[left[u]] : 0;
    const szR = right[u] !== -1 ? sz[right[u]] : 0;
    sz[u] = 1 + szL + szR;
    totalSum += arr[u] * (szL + 1) * (szR + 1);
  }
  return totalSum;
}

In a Min-Cartesian tree of A[0..N-1], an inorder traversal visits indices 0, 1, ..., N-1 in exact array order (BST on indices), and every parent has a smaller or equal array value than its children (Min-Heap on A[i]). Consequently, the root of any subtree is the minimum element of that contiguous index range.
Concept Check Tracing the Right-Spine Monotonic Stack Step apply

During the Θ(N)\Theta(N)Θ(N) left-to-right construction of a Min-Cartesian Tree, the monotonic stack maintains the current tree's **right spine** (indices with strictly increasing values from bottom to top). When inserting index iii, we pop all spine nodes sss with A[s]>A[i]A[s] > A[i]A[s]>A[i].

All popped nodes have indices `< i` and values `> A[i]`, and `lastPopped` was the highest ancestor among them (so `lastPopped`'s subtree already contains all the other popped nodes!). Attaching `lastPopped` as `left[i]` puts all those `< i` indices in `i`'s left subtree while restoring the min-heap invariant (`A[i] < A[lastPopped]`). Meanwhile, the remaining stack top `p` has index `< i` and value `<= A[i]`, so `i` becomes `right[p]`.
Concept Check Counting Subarrays Where A[i] Is the Minimum via Cartesian Tree apply

Once the Min-Cartesian Tree of A[0..N−1]A[0..N-1]A[0..N−1] is built, let `sz[u]` be the number of nodes in uuu's subtree, `szL = sz[left[u]]`, and `szR = sz[right[u]]$.

Because the inorder traversal of u's subtree is a contiguous block of array indices containing szL indices to the left of u (`[u - szL .. u - 1]`) and szR indices to the right of u (`[u + 1 .. u + szR]`), any subarray `[L, R]` with `L in [u - szL, u]` (szL + 1 choices) and `R in [u, u + szR]` (szR + 1 choices) has `LCA(L, R) = u` in the Cartesian tree!

Key Takeaways

A Cartesian tree for A[0..N-1] is a binary tree that is simultaneously a BST on array indices (inorder traversal is 0..N-1) and a min-heap on array values A[i].
Maintaining the right spine on a monotonic stack builds the Cartesian tree in exact Theta(N) time because every node is pushed once and popped at most once.
RMQ(L, R) on array A is identical to LCA(L, R) in the Cartesian tree of A, completing the bidirectional linear-time equivalence between RMQ and LCA.
In the Cartesian tree, the subtree rooted at i spans the exact maximal interval [L_i, R_i] where A[i] is the minimum, so A[i] is the minimum of (sz[left[i]] + 1) * (sz[right[i]] + 1) subarrays.
