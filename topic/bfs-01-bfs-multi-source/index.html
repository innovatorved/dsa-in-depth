Breadth-First Search: Multi-Source BFS, 0-1 BFS (Deque) & Bidirectional Search

6 min read Module 5.1: Graph Representations, Traversals, Connectivity & Topological Order Updated Oct 23, 2026
📄 Cheat Sheet

Demonstrates wave-front level expansion and shortest-path tree construction on unweighted graphs.

Intuition first

Breadth-First Search (BFS) is not merely a traversal order; it is a specialized instance of Dijkstra's shortest-path algorithm where edge weights are restricted to ${1}$ (or ${0, 1}$ in 0-1 BFS). Because all edges added to the frontier increase path distance by at most $1$, the priority queue collapses into a FIFO queue (or a double-ended queue), maintaining the sorted order of distances without $O(\log V)$ heap overhead.

By generalizing the initial frontier to multiple starting vertices (Multi-Source BFS), allowing zero-cost transitions pushed to the front of a deque (0-1 BFS), or expanding simultaneously from source and target (Bidirectional BFS), you can solve complex shortest-path problems in strict $O(V + E)$ linear time.

The Two-Valued Queue Monotonicity Invariant

Why does a simple FIFO queue suffice to compute exact shortest paths in unweighted graphs, and why does a double-ended queue (deque) suffice when edge weights are $w(u, v) \in \{0, 1\}$? The answer lies in the Two-Valued Queue Invariant.

Formal Invariant — Queue Monotonicity & Two-Level Bound

At any point during standard BFS or 0-1 BFS execution, if the deque contains vertices $\langle v_1, v_2, \dots, v_k \rangle$ from front to back, their tentative distances satisfy:

$$d[v_1] \le d[v_2] \le \dots \le d[v_k] \quad \text{and} \quad d[v_k] - d[v_1] \le 1$$

In 0-1 BFS, popping $u = v_1$ with minimum distance $d[u]$ and relaxing an edge $(u, x)$ produces either $d[x] = d[u]$ (via a weight-0 edge, pushed to the front before $v_2$) or $d[x] = d[u] + 1$ (via a weight-1 edge, pushed to the back after $v_k$, since $d[v_k] \le d[u] + 1$). Thus monotonicity is preserved inductively in $O(1)$ per operation.

1. Multi-Source BFS via Virtual Super-Source

Given a set of source vertices $S = \{s_1, s_2, \dots, s_k\}$ (such as all exit cells in a grid or all infected nodes in a network), finding $\min_{s \in S} \text{dist}(s, v)$ for every vertex $v \in V$ does not require $k$ separate BFS runs. Conceptually, introduce a virtual super-source $s^*$ with directed zero-weight edges $(s^*, s_i)$ for all $s_i \in S$. In code, simply initialize $d[s_i] = 0$ and push all $s_i \in S$ into the queue at step 0 before starting the loop. Every vertex $v$ is visited at most once in $O(V + E)$ total time.

2. 0-1 BFS with a Double-Ended Queue (Dial's $C=1$ Specialization)

Many grid and state-space problems have free transitions ($w = 0$, e.g., moving along a conveyor belt's direction or staying in the same corridor) and unit-cost modifications ($w = 1$, e.g., rotating a tile or breaking a wall). Standard BFS fails because a path with more edges can have lower total weight. Dijkstra's algorithm runs in $O((V + E) \log V)$, whereas 0-1 BFS achieves $O(V + E)$:

  • When relaxing $(u, v)$ with weight $w \in \{0, 1\}$, check if $d[u] + w < d[v]$.
  • If improved, update $d[v] = d[u] + w$. If $w == 0$, call dq.push_front(v); if $w == 1$, call dq.push_back(v).
  • Because a vertex $v$ might first be discovered via a weight-1 edge ($d[u] + 1$) and later relaxed via a weight-0 edge ($d[u'] + 0 = d[u]$), $v$ can be pushed into the deque at most twice. Popping a stale duplicate is skipped in $O(1)$ or guarded by a visited bitset upon pop.

3. Bidirectional BFS & Frontier Balancing

When searching for a shortest path between a single pair $(s, t)$ in a graph with branching factor $b$ and shortest-path distance $D$, standard BFS explores $\Theta(b^D)$ states. Bidirectional BFS maintains two frontiers $Q_f$ (expanding forward from $s$) and $Q_b$ (expanding backward along reversed edges from $t$). At each step, expand the frontier with fewer vertices ($|Q_f| \le |Q_b|$) by one full level. When the frontiers intersect at some vertex $m$, the shortest path has length $d_f[m] + d_b[m]$, and only $\Theta(2 \cdot b^{D/2})$ vertices are visited—turning $10^8$ states into $2 \times 10^4$.

Hardware Reality — std::deque Chunked Allocation vs. Ring Buffer

In C++ libstdc++ and libc++, std::deque is implemented as a dynamic array of pointers to fixed-size 512-byte blocks. While asymptotic $O(1)$, it introduces double indirection on index operations. For performance-critical 0-1 BFS where $|V| \le 10^6$, pre-allocating a flat array of size $2|V| + 5$ with initial head = V, tail = V provides a contiguous cache-resident deque with branchless pointer arithmetic.

Production Implementation: 0-1 BFS & Multi-Source BFS

C++20
#include <vector>
#include <deque>
#include <limits>

struct Edge01 {
    int to;
    int weight; // Must be 0 or 1
};

std::vector<int> zeroOneBFS(int n, const std::vector<std::vector<Edge01>>& adj,
                            const std::vector<int>& sources) {
    constexpr int INF = std::numeric_limits<int>::max() / 2;
    std::vector<int> dist(n, INF);
    std::vector<uint8_t> settled(n, 0);
    std::deque<int> dq;

    for (int s : sources) {
        dist[s] = 0;
        dq.push_front(s);
    }

    while (!dq.empty()) {
        int u = dq.front();
        dq.pop_front();
        if (settled[u]) continue;
        settled[u] = 1;

        for (const auto& e : adj[u]) {
            if (dist[u] + e.weight < dist[e.to]) {
                dist[e.to] = dist[u] + e.weight;
                if (e.weight == 0) {
                    dq.push_front(e.to);
                } else {
                    dq.push_back(e.to);
                }
            }
        }
    }
    return dist;
}
Failure Mode — Early Stopping Trap in Bidirectional BFS and 0-1 BFS

In standard BFS, you can mark a vertex visited at the exact moment it is pushed into the queue. In 0-1 BFS, marking a vertex final upon push is a bug: a vertex pushed to the back via a weight-1 edge at distance $d+1$ may subsequently be reached via a weight-0 edge at distance $d$. Always relax distances upon push and mark settled upon pop. Similarly, in Bidirectional BFS, the first vertex $v$ seen by both sides is not guaranteed to be the global minimum unless you expand a full level and take $\min_v (d_f[v] + d_b[v])$ across the entire layer.

Key Takeaways

Standard BFS and 0-1 BFS rely on the Two-Valued Queue Invariant: all elements in the deque have distances within {d, d+1} in non-decreasing order.
Multi-Source BFS computes the distance from every vertex to its nearest source in O(V + E) time by seeding the queue with all sources at distance 0.
In 0-1 BFS, weight-0 edges push to the front of the deque and weight-1 edges push to the back; vertices must be marked settled upon pop, not push.
Bidirectional BFS reduces state-space exploration from O(b^D) to O(b^(D/2)) by expanding the smaller frontier one complete level at a time.
