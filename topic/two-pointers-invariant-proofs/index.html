Intuition first

A two-pointer algorithm replaces an $O(N^2)$ nested loop over index pairs $(i, j)$ with an $O(N)$ linear progression by exploiting a monotonicity or partitioning invariant: every time a pointer advances by 1 step, it eliminates an entire row or column of the $(i, j)$ search matrix, or narrows the unclassified gap $[\text{mid} \dots \text{high}]$ by exactly one element.

0:00 / 3:16

Eliminating Rows and Columns in the Pair Search Matrix

Why does the converging two-pointer algorithm for sorted 2-Sum ($A[L] + A[R] = T$) never miss a valid pair? Visualize all possible index pairs $(L, R)$ with $0 \le L < R < N$ as an upper-triangular grid inside an $N \times N$ matrix, starting at the top-right corner $(L = 0, R = N - 1)$:

  • If $A[L] + A[R] < T$, since the array is sorted ($A[k] \le A[R]$ for all $k < R$), pairing the current $L$ with any smaller right index $k < R$ yields $A[L] + A[k] \le A[L] + A[R] < T$. Thus the entire row $L$ is provably invalid, and incrementing $L \leftarrow L + 1$ safely discards $R - L$ pairs in $O(1)$ time.
  • If $A[L] + A[R] > T$, since $A[k] \ge A[L]$ for all $k > L$, pairing the current $R$ with any larger left index $k > L$ yields $A[k] + A[R] \ge A[L] + A[R] > T$. Thus the entire column $R$ is provably invalid, and decrementing $R \leftarrow R - 1$ safely discards $R - L$ pairs in $O(1)$ time.

The exact same pruning proof governs the Container With Most Water problem ($\max (R - L) \cdot \min(H[L], H[R])$): if $H[L] \le H[R]$, then for every $k \in (L, R)$, the width $(k - L) < (R - L)$ and the height $\min(H[L], H[k]) \le H[L] = \min(H[L], H[R])$. Therefore, $L$ can never form a larger container with any $k < R$, justifying $L \leftarrow L + 1$.

Loop Invariant: Edsger Dijkstra's 3-Way Dutch National Flag Partition

To partition an array $A[0 \dots N-1]$ around a pivot $p$ into three contiguous regions ($< p$, $== p$, and $> p$) in a single $O(N)$ pass with $O(1)$ auxiliary space, maintain three pointers $\text{low}$, $\text{mid}$, and $\text{high}$ satisfying the four-region loop invariant at the start of every iteration:

  1. $\forall k \in [0, \text{low} - 1]: A[k] < p$ (strictly less than pivot)
  2. $\forall k \in [\text{low}, \text{mid} - 1]: A[k] == p$ (equal to pivot)
  3. $\forall k \in [\text{mid}, \text{high}]: A[k]$ is unclassified / unknown
  4. $\forall k \in [\text{high} + 1, N - 1]: A[k] > p$ (strictly greater than pivot)

Potential Function (Termination Proof): Define $\Phi = \text{high} - \text{mid} + 1$, the size of the unclassified region. Initially $\text{low} = 0, \text{mid} = 0, \text{high} = N - 1$, so $\Phi = N$ and regions 1, 2, and 4 are vacuously empty. Each step inspects $A[\text{mid}]$ and either increments $\text{mid}$ or decrements $\text{high}$, strictly decreasing $\Phi$ by 1 until $\Phi = 0$ ($\text{mid} > \text{high}$), terminating in exactly $N$ comparisons.

Hardware Reality: Hardware Prefetchers Love Bidirectional Sequential Streams

Modern x86-64 (Intel Golden Cove / AMD Zen 4) and ARM Neoverse L2 stream prefetchers track both ascending (+1 stride) and descending (-1 stride) memory accesses per 4 KB page independently. Consequently, converging two-pointer scans ($L$ moving up from $0$, $R$ moving down from $N-1$) sustain near-100% L1 data cache hit rates. However, inside the Dutch National Flag loop, the 3-way branch on random data causes ~50% branch misprediction penalties (15–20 cycles per mispredict). High-performance sorting libraries (such as pdqsort, Pattern-Defeating Quicksort in Rust's standard library) eliminate this branch bottleneck using BlockQuicksort: evaluating comparisons into small branchless offset buffers via conditional moves (cmov) before executing a tight swap loop.

Production Implementation: Dijkstra's 3-Way Partition & O(1)-Space Trapping Rain Water

C++20
#include <algorithm>
#include <cstdint>
#include <utility>
#include <vector>

// Returns {low, high} bounds of the equal-to-pivot range [low .. high]
template <typename T>
std::pair<std::size_t, std::size_t> dutch_flag_partition(std::vector<T>& a, const T& pivot) noexcept {
  if (a.empty()) return {0, 0};
  std::size_t low = 0;
  std::size_t mid = 0;
  std::size_t high = a.size(); // Use half-open [mid, high) to avoid unsigned underflow!

  while (mid < high) {
    if (a[mid] < pivot) {
      std::swap(a[low], a[mid]);
      ++low;
      ++mid;
    } else if (a[mid] == pivot) {
      ++mid;
    } else {
      --high;
      std::swap(a[mid], a[high]);
      // Critical: do NOT increment mid; the element swapped from a[high] is unclassified!
    }
  }
  return {low, high};
}

// O(N) Time, O(1) Space Converging Two-Pointer Trapping Rain Water
// Invariant: if height[left] <= height[right], then max_left <= max_right (or height[right]
// acts as a guaranteed right-hand wall >= height[left]), so water at left is bounded
// exclusively by max_left.
std::int64_t trap_rain_water(const std::vector<int>& height) noexcept {
  if (height.size() < 3) return 0;
  std::size_t left = 0, right = height.size() - 1;
  int max_left = height[left], max_right = height[right];
  std::int64_t trapped = 0;

  while (left < right) {
    if (max_left <= max_right) {
      ++left;
      max_left = std::max(max_left, height[left]);
      trapped += (max_left - height[left]);
    } else {
      --right;
      max_right = std::max(max_right, height[right]);
      trapped += (max_right - height[right]);
    }
  }
  return trapped;
}
Production Pitfall: Incrementing mid After Swapping with high & Unsigned Underflow

In the Dutch National Flag partition, the #1 bug is incrementing mid in the A[mid] > pivot branch after swap(A[mid], A[high]). When you swap A[low] and A[mid], you already know A[low] == pivot (unless low == mid), so mid can safely advance. When you swap A[mid] and A[high], the value coming from A[high] was inside the unclassified region—incrementing mid skips inspecting it! Furthermore, if high is a size_t initialized to N - 1 and every element exceeds the pivot, --high underflows to SIZE_MAX. Always maintain the unclassified region as a half-open interval [mid, high) where high starts at N.

Concept Check Dijkstra's Dutch National Flag 4-Region Invariant recall

In Dijkstra's 3-way Dutch National Flag partition around pivot $p$, pointers `low`, `mid`, and `high` partition the array into four regions: $[0 \dots \text{low}-1] < p$, $[\text{low} \dots \text{mid}-1] == p$, $[\text{mid} \dots \text{high}]$ unclassified, and $[\text{high}+1 \dots N-1] > p$.

When `A[mid] < p`, we swap `A[low]` and `A[mid]` and increment both `low` and `mid` because `A[low]` belonged to the `== p` region (or `low == mid`). By contrast, `A[high]` belonged to the unclassified region $[\text{mid} \dots \text{high}]$, so the newly arrived value at `A[mid]` must be inspected on the next iteration.
Concept Check Container With Most Water Pruning Proof apply

In the Container With Most Water problem, we start with $L = 0, R = N - 1$ and area $(R - L) \cdot \min(H[L], H[R])$. Suppose at the current step $H[L] \le H[R]$, and we increment $L \leftarrow L + 1$ without ever testing pairs $(L, R-1), (L, R-2), \dots, (L, L+1)$.

Since $H[L] \le H[R]$, the left wall $H[L]$ is the bottleneck limiting the height of $(L, R)$ to $H[L]$. Pairing $L$ with any narrower right endpoint $k < R$ strictly shrinks the width $(k - L < R - L)$ while the height $\min(H[L], H[k])$ can never exceed $H[L]$. Thus row $L$ of the pair matrix is completely dominated by $(L, R)$.
Concept Check O(1)-Space Two-Pointer Trapping Rain Water Invariant apply

In the $O(1)$-space two-pointer algorithm for Trapping Rain Water, we maintain `left = 0`, `right = N - 1`, `max_left = H[0]`, and `max_right = H[N - 1]`. Whenever `max_left <= max_right`, we advance `left` and add `max_left - H[left]` to the total water.

The true highest wall to the right of `left` is at least as tall as the highest wall seen so far in `[right .. N-1]` (`true_max_right >= max_right`). When `max_left <= max_right`, transitivity gives `max_left <= max_right <= true_max_right`, so $\min(\text{max\_left}, \text{true\_max\_right}) = \text{max\_left}$.

Key Takeaways

Converging two-pointer algorithms run in O(N) by proving that each step eliminates an entire row or column of the N x N pair search matrix.
Dijkstra's 3-way Dutch National Flag partition maintains four contiguous regions: [0..low) < p, [low..mid) == p, [mid..high) unclassified, and [high..N) > p.
When swapping A[mid] with the unclassified element at the high boundary, never increment mid—the incoming element has not yet been compared against the pivot.
Use a half-open unclassified boundary [mid, high) with high initialized to N to prevent unsigned integer underflow when all elements exceed the pivot.
