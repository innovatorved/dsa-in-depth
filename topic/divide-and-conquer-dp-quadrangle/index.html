Explains the Quadrangle Inequality (Monge condition), decision monotonicity opt[k][i] <= opt[k][i+1], and the recursive midpoint split.

Intuition first

But if the segment cost function C(j,i)C(j, i)C(j,i) is 'supermodular' (satisfies the Quadrangle Inequality), the optimal split point opt[i]\text{opt}[i]opt[i] never moves backward as iii moves right! Computing opt[mid]\text{opt}[\text{mid}]opt[mid] first sandwiches the left half's splits to [optL,opt[mid]][\text{opt}_L, \text{opt}[\text{mid}]][optL​,opt[mid]] and the right half's splits to [opt[mid],optR][\text{opt}[\text{mid}], \text{opt}_R][opt[mid],optR​], dropping each layer from O(N2)O(N^2)O(N2) to O(Nlog⁡N)O(N \log N)O(NlogN).

1. The KKK-Partition Recurrence & Decision Monotonicity

Many partitioning and clustering problems (such as kkk-medians on a line, partitioning an array into KKK subarrays to minimize sum of squared sums, or Optimal Batching) have the layered recurrence for k=1…Kk = 1 \dots Kk=1…K and i=1…Ni = 1 \dots Ni=1…N:

dp[k][i]=min⁡0≤j<i(dp[k−1][j]+C(j,i))dp[k][i] = \min_{0 \le j < i} \big(dp[k-1][j] + C(j, i)\big)dp[k][i]=0≤j<imin​(dp[k−1][j]+C(j,i))

Evaluating all pairs (j,i)(j, i)(j,i) for each layer kkk takes O(K⋅N2)O(K \cdot N^2)O(K⋅N2) time. Let opt[k][i]\text{opt}[k][i]opt[k][i] be the smallest index jjj that minimizes dp[k−1][j]+C(j,i)dp[k-1][j] + C(j, i)dp[k−1][j]+C(j,i).

Core Invariant — The Quadrangle Inequality (Monge Property) & Monotonicity of opt

A 2D cost function C(j,i)C(j, i)C(j,i) satisfies the Quadrangle Inequality (Inverse Monge Property for Minimization) if for all a≤b≤c≤da \le b \le c \le da≤b≤c≤d:

C(a,c)+C(b,d)≤C(a,d)+C(b,c)C(a, c) + C(b, d) \le C(a, d) + C(b, c)C(a,c)+C(b,d)≤C(a,d)+C(b,c)

Intuitively: "Two nested intervals (a,d)(a, d)(a,d) and (b,c)(b, c)(b,c) cost MORE than two crossing/disjoint intervals (a,c)(a, c)(a,c) and (b,d)(b, d)(b,d)" (the marginal penalty of extending an interval grows as the interval gets longer—convexity!).
Theorem: If C(j,i)C(j, i)C(j,i) satisfies the Quadrangle Inequality, then for every fixed layer kkk, the optimal transition decision is monotonically non-decreasing:

opt[k][0]≤opt[k][1]≤⋯≤opt[k][N]\text{opt}[k][0] \le \text{opt}[k][1] \le \dots \le \text{opt}[k][N]opt[k][0]≤opt[k][1]≤⋯≤opt[k][N]

2. The Divide-and-Conquer Recursion (O(KN2)→O(KNlog⁡N)O(K N^2) \to O(K N \log N)O(KN2)→O(KNlogN))

To compute a single layer dp_cur[l..r] given that we already know opt[i]∈[optL,optR]\text{opt}[i] \in [\text{opt}_L, \text{opt}_R]opt[i]∈[optL​,optR​] for all i∈[l,r]i \in [l, r]i∈[l,r]:

  1. Pick the midpoint mid=⌊(l+r)/2⌋\text{mid} = \lfloor (l + r) / 2 \rfloormid=⌊(l+r)/2⌋.
  2. Scan j∈[optL,min⁡(mid−1,optR)]j \in [\text{opt}_L, \min(\text{mid} - 1, \text{opt}_R)]j∈[optL​,min(mid−1,optR​)] linearly to find best_j=opt[mid]\text{best\_j} = \text{opt}[\text{mid}]best_j=opt[mid] and set dp_cur[mid].
  3. By monotonicity, every i<midi < \text{mid}i<mid has opt[i]∈[optL,best_j]\text{opt}[i] \in [\text{opt}_L, \text{best\_j}]opt[i]∈[optL​,best_j], and every i>midi > \text{mid}i>mid has opt[i]∈[best_j,optR]\text{opt}[i] \in [\text{best\_j}, \text{opt}_R]opt[i]∈[best_j,optR​].
  4. Recurse on [l, mid - 1] with search range [opt_L, best_j] and on [mid + 1, r] with [best_j, opt_R]!

Why does each layer take O(Nlog⁡N)O(N \log N)O(NlogN) time? Because at each depth of the recursion tree (depth ≤⌈log⁡2N⌉\le \lceil \log_2 N \rceil≤⌈log2​N⌉), the decision intervals [optL,optR][\text{opt}_L, \text{opt}_R][optL​,optR​] are disjoint except at their shared boundary endpoints best_j\text{best\_j}best_j, so their lengths sum to at most N+2d=O(N)N + 2^d = O(N)N+2d=O(N) per depth!

4. Reference C++20 Implementation

C++2050 lines
#include <algorithm>
#include <cstdint>
#include <vector>

// Partition array <code>a</code> of length N into K non-empty subarrays to minimize sum of (subarray_sum)^2
// C(j, i) = (pref[i] - pref[j])^2 satisfies Quadrangle Inequality: C(a,c) + C(b,d) <= C(a,d) + C(b,c)
long long partition_min_sum_of_squares_dnc(const std::vector<long long>& a, int k_parts) {
    const int n = static_cast<int>(a.size());
    constexpr long long INF = 1LL << 60;

    std::vector<long long> pref(n + 1, 0);
    for (int i = 0; i < n; ++i) pref[i + 1] = pref[i] + a[i];

    auto cost = [&](int j, int i) -> long long {
        long long diff = pref[i] - pref[j];
        return diff * diff;
    };

    std::vector<long long> dp_prev(n + 1, INF), dp_cur(n + 1, INF);
    dp_prev[0] = 0;

    auto compute = [&](auto& self, int l, int r, int opt_l, int opt_r) -> void {
        if (l > r) return;
        int mid = l + (r - l) / 2;

        long long best_val = INF;
        int best_j = opt_l;
        int upper_j = std::min(mid - 1, opt_r);

        for (int j = opt_l; j <= upper_j; ++j) {
            if (dp_prev[j] == INF) continue;
            long long val = dp_prev[j] + cost(j, mid);
            if (val < best_val) {
                best_val = val;
                best_j = j;
            }
        }
        dp_cur[mid] = best_val;

        self(self, l, mid - 1, opt_l, best_j);
        self(self, mid + 1, r, best_j, opt_r);
    };

    for (int k = 1; k <= k_parts; ++k) {
        std::fill(dp_cur.begin(), dp_cur.end(), INF);
        compute(compute, k, n, k - 1, n - 1);
        std::swap(dp_prev, dp_cur);
    }
    return dp_prev[n];
}

Key Takeaways

A cost function C(j, i) satisfies the Quadrangle Inequality (Monge property) if C(a, c) + C(b, d) <= C(a, d) + C(b, c) for all a <= b <= c <= d.
The Quadrangle Inequality implies decision monotonicity: opt[k][i] <= opt[k][i+1] across each layer k.
Divide-and-Conquer DP computes opt[k][mid] first and restricts the left recursion to [opt_L, opt[mid]] and the right recursion to [opt[mid], opt_R], reducing each layer from O(N^2) to O(N log N).
Because all decision intervals at a single recursion depth sum to O(N), sliding-window cost functions C(j, i) can be maintained with two pointers in O(K N log N) total time.
